# ImageTaken

<img src="extension/assets/imagetaken-logo.png" alt="ImageTaken Logo" width="144">

一个原生 JavaScript、零运行时依赖的 Chrome 图片下载扩展，支持侧边栏浏览、筛选、框选和批量保存图片。

[GitHub 仓库](https://github.com/tellok/chrome-extension-imagetoken)

## 安装

需要 Chrome 116 或更新版本，扩展无需构建。

1. 克隆仓库，或下载并解压扩展 ZIP。
2. 打开 `chrome://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库的 **`extension` 文件夹**，或包含 `manifest.json` 的解压目录。
4. 打开网页，点击 ImageTaken 图标打开侧边栏；右上角 `↗` 可打开独立标签页。

更新本地代码后，在扩展管理页点击「重新加载」。

## 使用

- 点击图片卡片选择图片，也可以拖动鼠标框选；通过搜索、尺寸、格式和网站规则缩小范围。
- 编辑页面标题，选择下载位置，然后下载选中图片。图片保存在以页面标题命名的子文件夹中。
- 宽高与体积阈值按网站保存；在设置页配置全局默认宽高，供未单独设置的网站使用。未单独配置的宽高显示“全局默认(数值)”，输入框旁的还原按钮可分别恢复继承；设为 0 则取消限制。
- 点击齿轮打开设置，调整语言、明暗主题、标题清洗和成功图片优先展示。
- [配置同步](docs/settings-sync.md)默认开启，每台机器可独立关闭；遇到不同配置时在设置页选择版本。跨设备需要 Chrome 账户与浏览器同步。
- 设置中可添加[远程规则订阅](docs/remote-rules.md)，按页面域名与路径应用规则；本地配置优先，默认不订阅任何源。
- “下载 → 同时下载图片清单”默认关闭；开启后每批在图片目录保存一份以编辑后标题命名的 `.txt`，记录实际文件名、来源、图片原标题和采集时间。
- 懒加载内容先在原网页滚动或展开，再点击扩展的刷新按钮。下载期间保持扩展视图打开。

扩展优先复用完整原图及网页归档，再尝试普通请求和两种来源请求。普通使用默认不附加调试连接；仍找不到图片时，可从列表底部进入设置，为当前网站开启“增强模式”。开启后会补充发现和提取，列表底部可直接关闭。Chrome 在实际增强读取时可能显示调试提示，结束后释放连接。原格式下载保留完整文件，静态像素仅用于预览或明确的格式转换；受权限、跨域、地址失效或资源释放影响，部分图片可能无法保存。

升级后沿用此前保存的全局宽高；此前的全局体积不分配给网站，未设置网站的体积使用 2 KiB。

图片处理在本机完成，无遥测或自有后端；开启配置同步时，Chrome 会复制设置、网站规则、搜索词、忽略摘要和订阅地址，目录授权及图片缓存仍留本机；预览与下载可能访问原图片服务器，启用订阅后会定期访问用户添加的规则源。

## 开发

```sh
npm run check       # Manifest 引用与 JavaScript 语法
npm test            # 单元测试
npm run package     # 生成扩展 ZIP
```
