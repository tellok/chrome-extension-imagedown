# ImageTaken

<img src="extension/assets/imagetaken-logo.png" alt="ImageTaken Logo" width="144">

[GitHub 仓库](https://github.com/tellok/chrome-extension-imagetoken)


一个原生 JavaScript、零运行时依赖的 Chrome Manifest V3 图片下载扩展。参考 Imageye 的图片浏览和批量下载工作流，独立实现代码与界面。

核心原则：**发现图片与读取图片分开。页面已经展示的图片，不应因为扩展再次请求失败而从列表中消失。**

## 界面

0.4.0 使用受 Notion 启发的文档与图库界面：纸白底色、黑灰层级、细边框、紧凑工具栏、低圆角图片卡片和黑色下载按钮。侧边栏与独立标签页共用响应式布局；图标使用本地 SVG，图片本身保留原始颜色。

标题区和空状态包含两张为本项目独立生成的黑白线描插图，扩展运行时完全从本地加载，没有远程字体、设计服务或图片服务依赖。素材、生成方式及完整提示词见 [插图说明](docs/illustrations.md)。这是 ImageTaken 自身的界面设计，不隶属于 Notion。

## 安装

需要 Chrome 116 或更新版本。

1. 克隆此仓库，或下载并解压打包后的 ZIP。
2. 打开 `chrome://extensions`，启用右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库的 **`extension` 文件夹**，或包含 `manifest.json` 的 ZIP 解压目录。
4. 打开网页，点击 ImageTaken 图标，在侧边栏查看图片。右上角 `↗` 可以打开独立标签页。
5. 点击图片卡片或复选框切换选择，也可以从卡片或列表空隙拖动鼠标框选追加图片（Ctrl / ⌘ + 框选反选，Esc 取消本次框选）。拖到窗口边缘可自动滚动继续框选。列表上方的「全选」只勾选成功加载预览的图片，跳过失败及仍在加载的图片；取消全选清除当前列表的全部选择，被筛选隐藏的选择保留。点击下载后，图片保存到下载位置下以页面标题命名的子文件夹。

页面中的懒加载内容需要先滚动或展开，再点击 `↻` 重新扫描。批量下载期间保持侧边栏或独立标签页打开。Chrome 的下载询问、站点访问权限及企业策略可能影响下载。

工具栏 Logo 的红色数字徽标自动显示当前网页成功加载的图片数量，无需先打开侧栏。监听脚本在文档创建时启动，图片加载成功就会更新，不等待整页及广告、统计脚本等慢资源全部完成。页面加载、懒加载、图片增删及 iframe 变化会触发节流更新；相同地址去重，失败或尚未加载的图片不计入。后台计数遵循已保存的尺寸、体积、搜索、XPath、CSS 排除及忽略规则，只检查页面状态和元数据，不导出像素、不额外请求图片，也不启动 debugger。打开图片库后，徽标改用该视图当前筛选结果中成功加载预览的数量；关闭视图后恢复网页自动计数。计数按标签页隔离，导航时清除旧值并重新计算。扫描中显示 `…`，超过 999 张显示 `999+`，完整数量和识别情况保留在悬停提示中。

「搜索图片地址或描述」自动按当前网页 hostname 保存最后输入的内容，重新打开、重新扫描或访问同域名其他页面时自动恢复；不同域名及子域名分别记忆，同域名不区分协议、端口和路径。清空搜索框或点击「清除筛选」会清除当前域名的搜索缓存；恢复默认阈值保留搜索内容。

### 下载位置与页面标题

默认跟随浏览器设置的下载位置。页面顶部标题编辑区下方仅显示基准下载位置和目录选择按钮，不展示标题子目录；名称过长时单行省略，悬停可查看完整目录名称。点击「选择目录」，通过系统目录选择器指定本地磁盘文件夹；浏览器可能要求授予写入权限。选择结果保存在本机，重新打开面板仍会使用它；取消选择保留原设置。「恢复默认」切回浏览器默认下载位置。浏览器不向扩展提供选中目录的完整磁盘路径，界面显示目录名称。若侧边栏中的目录选择被浏览器限制，可通过右上角 `↗` 在独立标签页重新选择。

默认标题来自当前网页。点击页面顶部的标题或铅笔图标进入编辑，输入框保留完整原标题，光标位于末尾，不自动全选。绿色勾确认、红色叉或 Esc 放弃；点击编辑区外会确认当前内容，Enter 也可确认。空白内容恢复网页原标题。自定义标题在当前面板重新扫描同一网址时保留，切换网页或重新打开面板后取新的网页标题。长标题在展示时省略，悬停可查看全文；编辑框支持换行显示和滚动。

单张和批量下载统一保存到 `所选位置/页面标题/图片文件`，不再固定创建 `ImageTaken` 目录。开始下载时固定本次标题及位置；同一标题使用同一子文件夹。同名文件比较 SHA-256：内容相同则跳过，内容不同则保留文件名主体，在扩展名前添加随机字符串，例如 `001-photo_a17c398b604f02de.jpg`，保留已有文件；已生成的随机后缀版本也参与去重。界面分别统计新保存与跳过的图片。标题中的非法路径字符会替换，系统保留名会加前缀，目录名限制为 120 个 UTF-8 字节，空目录名使用「未命名页面」；界面显示实际生成的目录名。

自定义目录会读取磁盘上现有文件的实际内容计算哈希。浏览器默认位置没有任意文件读取权限，只能依据本扩展保存的哈希及 Chrome 下载记录去重，无法核验外部修改；未记录哈希、下载记录已删除或直接 URL 兜底下载的同名文件，会添加随机后缀保留。要按已有磁盘文件的实际内容比较，请先用「选择目录」授权该文件夹。默认位置需通过实际下载确定当前路径，遇到重名时会移除本次生成的临时副本；Chrome 下载记录可能保留已移除的临时条目。

自定义目录采用 File System Access API 写入，文件写入并关闭后才算成功；授权失效时在点击下载时重新申请，拒绝授权或目录不可用会停止本次任务并提示，不会改存其他位置。普通浏览器下载仍保留直接下载原始 URL 的兜底；自定义目录仅保存成功读取的图片数据，超出读取限制或无法读取的资源会报告失败。自定义目录写入的文件不显示在 Chrome 下载记录中。

默认位置下载在 Chrome 最终确定文件名时再次指定标题子目录，兼容其他下载扩展监听文件名的情况。下载完成后还会核对实际路径；如果其他扩展改写目录，会提示「已下载 · 目录异常」，不会报告已归档成功。底部「打开下载位置」可在文件管理器中定位最近的浏览器下载。Chrome 允许较晚安装或更新的其他扩展覆盖文件名，遇到持续冲突可选择本地目录直接写入。

## 已实现

- 页面图片 `currentSrc` / `src`、`picture` / `srcset` 候选、常见懒加载属性。
- CSS 背景、遮罩、边框图片、列表图片及 `::before` / `::after` 图片。
- Blob / Data URL、Canvas、内嵌 SVG、SVG image、视频封面、图片链接、资源时间线中的图片地址。
- 开放的 Shadow DOM；有权限访问的跨域 iframe。相同地址去重，保留各框架的读取入口。
- URL / 描述搜索，宽高、体积、格式、来源及页面已加载状态筛选，按页面遍历顺序、面积、宽度排序。
- 网格 / 列表布局，单张或批量下载，PNG / JPG / WebP 转换。
- 图片列表直接显示体积（B / KiB / MiB），区分已知值和估算值；显示读取方式、下载后大小或失败原因。
- 加载失败的预览支持逐张「重试加载」，以及全局「重试所有失败图片」；保持选择、筛选和忽略状态。
- 默认隐藏宽度低于 50 px、高度低于 50 px 或体积低于 2 KiB 的图片；阈值可配置并自动保存在本地。
- 按当前网页 hostname 保存图片忽略规则，支持一键忽略、显示已忽略图片及取消忽略。

这是核心图片下载工作流的实现；不包含 Imageye 的反向搜图、选区截图、ZIP 合并下载及全部站点专用适配。

## 网站采集规则：XPath 与 CSS 排除

图片列表末尾显示当前网站已保存的 XPath 范围和 CSS 排除规则，未配置的项目会显示「未配置」。摘要随页面滚动，滚到最底部时位于下载按钮区域上方；上方原有筛选和规则编辑控件保持不变。未保存的编辑不会改变摘要。

在「图片范围」粘贴 Chrome DevTools Elements 中右键节点 → Copy → Copy XPath / Copy full XPath 的结果，然后点击「保存并应用」。例如 `//*[@id="content"]` 或 `/html/body/main/div[2]`。范围包含匹配元素本身及其子树，因此直接选择 `<img>` 也可以；多个节点的结果合并去重。只接受节点集合，不接受 `$x(...)` JavaScript 命令或 `count(...)` 标量表达式。

「排除图片」支持一条或多条 CSS 选择器，每行一条，也可以使用逗号分隔，例如：

```css
.img-xxx
.advertisement img
[data-role="avatar"], .site-logo
```

`.img-xxx` 排除具有这个 class 的图片；匹配容器时同时排除其子树中的图片、背景、伪元素、Canvas 等。相同地址如果还被范围内其他未排除元素引用，仍然保留。开启 XPath 或 CSS 排除后，资源时间线仅补充已经从允许的 DOM 元素发现的图片体积，不新增没有 DOM 归属的资源，避免已排除的图片从资源记录重新出现。

处理顺序是 **XPath 范围 → CSS 排除 → 图片去重 → 宽高、体积、格式、搜索、忽略等现有筛选**。XPath 留空时使用全页范围。XPath 启用时仅扫描主文档，不独立匹配 iframe 的相似路径；未配置 XPath 时仍支持有权限访问的 iframe。主文档中的开放 Shadow DOM 可随宿主子树采集，XPath 本身不跨越 Shadow DOM 边界。

两种规则按顶层网页的 hostname 保存到本机，包含所有路径、协议、端口，不同子域名独立。重新打开面板、重新扫描或切换同域页面时自动应用。语法错误不保存；无匹配时显示空结果及提示，不自动退回全页。「清除网站规则」清空当前域名的 XPath 与 CSS 排除，保留尺寸阈值及已忽略图片；「清除筛选」只清除普通筛选，不更改网站规则。

ImageTaken 使用蓝色圆角画框、双山形和左下角咖啡壶图案。Logo 已用于扩展工具栏、扩展管理页、图片库与设置页标题栏、标签页图标及本 README，主 Logo 提供 16 / 32 / 48 / 128 px 版本；工具栏使用缩薄外围边框、放大蓝色主体的小尺寸适配版，另提供 24 px 档，全部从本地加载。选用的原图、尺寸生成方法和深浅背景预览见 [Logo 说明](docs/logo.md)。

## 重试加载失败的图片

预览加载失败时，卡片显示「重试加载」，列表上方显示失败数量和「重试所有失败图片」。重试会重新读取页面资源，再尝试扩展请求；HTTP 请求使用 `cache: reload` 绕过旧的失败缓存，不给 URL 追加参数，因此保留原始签名链接。

全局重试处理所有已发现的加载失败项，包括被搜索或尺寸 / 体积筛选隐藏的图片；默认跳过已忽略的图片，勾选「显示已忽略的图片」后可将它们纳入重试。尚未触发加载的离屏懒加载预览不计为失败。批量重试并发为 2，显示成功 / 失败数量，持续失败的图片保留按钮及具体原因，可再次点击。

重试不会自动下载文件，不清空选择、筛选、忽略规则或已有下载结果。恢复成功后更新预览、尺寸、格式与源数据体积，并重新应用当前筛选；恢复出的图片若不满足阈值，可能被筛选隐藏。成功的重试结果在当前列表保留，切换布局或筛选不会再次请求该资源。重新扫描、切换源网页或关闭面板时释放临时预览数据；旧页面尚未结束的重试不会覆盖新页面列表。预览重试期间暂时禁用下载操作，避免任务冲突。

## 默认筛选与图片体积

默认最小宽度 **50 px**、最小高度 **50 px**、最小体积 **2 KiB（2048 字节）**。低于任一阈值时隐藏，恰好等于阈值时保留。修改阈值会自动保存到 `chrome.storage.local`，跨面板和重启继续使用；设为 0 取消对应限制。「清除筛选」将三个阈值设为 0，「恢复默认阈值」恢复 50 / 50 / 2。

文件大小优先使用浏览器资源记录里的 HTTP 内容解码后响应体字节数、Data URL 解码后的字节数、Canvas PNG 快照大小或实际读取的图片字节数。忽略错误 HTTP 响应的响应体，避免把 404 / 403 HTML 页面大小误当成图片大小。不使用包含 HTTP 响应头的 `transferSize`，也不把 Base64 字符串长度或 RGBA 内存占用当作文件大小。

无法确定实际体积时，根据原始像素尺寸和图片格式估算压缩体积，显示 `≈`，悬停可查看依据及字节数。估算可能与实际压缩文件有较大差异，也会参与体积筛选；可降低阈值或设为 0 查看这些图片。尺寸或体积完全未知的图片不会仅因未知而被默认隐藏；预览获取尺寸后会重新应用筛选。列表中的源数据大小与转换后的下载文件大小分别显示，不额外发送 HEAD 或为计算体积批量重新下载原图。

## 网站图片忽略规则

点击图片卡片的「忽略」，该图片会立即隐藏并取消选择。勾选「显示已忽略的图片」可查看并逐张「取消忽略」；此开关默认关闭，不改变其他筛选条件。恢复默认阈值或清除筛选不会删除忽略规则。

规则以**顶层网页的 hostname** 分组，包含该域名的所有页面路径、协议及端口；不同子域名分别保存。iframe / CDN 图片也归当前顶层网页域名。存储中只保存域名和版本化 SHA-256 哈希，不保存完整图片 URL 或 Base64 数据。

图片元数据的稳定标识按来源区分：

- URL 文件：规范化的完整资源地址（包括图片自身的路径、查询及片段）生成元数据哈希。可变尺寸、估算体积、下载后补全的 MIME 不参与哈希，避免重新扫描或下载后规则失效。同一地址对应的图片仍被忽略；不同查询参数的图片独立识别。
- Data / Base64：先解码图片字节，再对 MIME、字节数及内容摘要生成元数据哈希。百分号转义、Base64 空白 / 补位变化不会使同一数据生成不同规则；不同内容不会仅因尺寸相同而互相忽略。
- Blob / 可读 Canvas：使用 PNG 缩略像素摘要和原始宽高生成元数据哈希，不使用 Blob 的随机 UUID 或 Canvas 所在页面的路径。相同像素的 Blob 地址重新生成后仍可识别；动画帧或画布内容变化时指纹可能变化。无法获取稳定像素指纹时禁用忽略按钮并提示原因。

写入规则由后台串行处理，避免两个面板同时忽略图片时覆盖彼此。规则及阈值仅存储在本机，卸载扩展时删除。

## 为什么可以显示，却读不出文件？

浏览器允许 `<img>` 显示很多跨域图片，但不一定允许脚本读取它们的响应字节或像素。跨域图片没有相应 CORS 授权时，画到 Canvas 会污染画布，`toDataURL()` 等读取操作会抛出 `SecurityError`。扩展具有站点权限也不会自动解除页面 Canvas 的限制。

另外，页面加载图片时可能带有登录 Cookie、来源 Referer、临时签名或特定缓存分区；扩展重新发起请求时上下文可能不同，原始地址也可能已经过期。普通页面脚本无法直接导出任意已渲染图片的原始压缩文件。本扩展现在使用 `chrome.debugger`，尝试读取浏览器仍保留的图片资源原始字节；不需要安装系统 App。

本扩展在用户下载时，按以下顺序尝试读取：

| 顺序 | 方法 | 输出 |
| --- | --- | --- |
| 0 | 通过 `chrome.debugger` 的 `Page.getResourceContent` 读取浏览器保留的 HTTP(S) 图片资源 | 原始文件字节，保留动画；不重新请求图片 URL |
| 1 | 直接使用 Data URL；在所属页面读取 Blob；导出扫描时的 Canvas 快照 | 内嵌数据、原 Blob，或 Canvas PNG |
| 2 | 同源 HTTP 图片使用 `only-if-cached`，不触发网络请求 | 缓存命中时保留原文件字节 |
| 3 | 在图片所属页面使用 `force-cache` 请求，带页面凭据与默认来源信息 | 优先命中缓存；未命中时可能访问网络 |
| 4 | 若图片元素仍持有相同地址的已解码图像，且画布允许读取，则导出像素 | 静态 PNG，明确显示「页面像素兜底」 |
| 5 | 扩展凭站点权限发起图片请求 | 成功时保留响应原文件 |
| 6 | 原格式下载仍失败时，交给 `chrome.downloads` 直接下载 HTTP(S) 地址 | 以浏览器实际完成 / 中断状态为准 |

扫描时先批量读取浏览器保留的图片资源，用于预览并复用到下载；每批最多 8 MiB，单张读取最多 20 MiB。每批完成立即断开调试连接，不刷新页面、不禁用缓存。Chrome 125+ 同时支持独立进程的跨域 iframe；旧版本无法读取的资源沿用回退路径。页面导航后会校验原文档身份，避免读取错误页面。

Chrome 会显示调试相关提示。用户取消调试后，当前页面停止尝试连接，直到页面重新导航；被其他调试器占用或资源已释放时自动回退。

缓存命中不保证总能发生。步骤 4 仍然受 Canvas 安全规则限制。普通跨域图片通常可以由步骤 5 读取，但依赖页面 Referer、受访问控制或地址过期的资源仍可能失败；失败原因会保留。

格式转换及像素兜底会重新编码，不能保留 GIF / WebP 动画、原始元数据或原文件编码。JPG 转换将透明区域填充为白色。Canvas 保存扫描时的快照。

技术参考：[Chrome 跨域请求与权限](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[MDN 跨域图片与 Canvas](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image)。

## 边界与性能

- 只支持 HTTP(S) 网页；浏览器内部页、Chrome 商店、内置 PDF 阅读器等受限制页面不支持。
- 无法访问关闭的 Shadow DOM、没有权限或受浏览器保护的框架；没有重放图片加载前的网络流量，也不绕过访问控制。
- 只扫描当前 DOM 和仍可查询的资源条目，不自动滚动页面，也不保证发现尚未创建的懒加载元素。
- 「页面已加载」指图片元素已解码或画布 / SVG 已渲染，不代表元素在当前视口可见；CSS 图片没有相同的解码状态接口。
- 列表顺序为主框架 DOM 遍历顺序，再加其他框架；不是不同框架之间的全局视觉坐标排序。
- 每框架最多 4000 个唯一地址、12 MiB 地址数据；缩略图预算约 6 MiB。达到上限会提示。
- 保留最近 3 次扫描的读取入口，避免侧边栏和独立标签页互相使读取入口失效；更旧的列表需要刷新。每次扫描的 Canvas 快照数据预算为 32 MiB。
- 原文件数据读取限制 20 MiB；像素导出和格式转换限制 2400 万像素。过大 HTTP(S) 文件可回退到浏览器原格式直接下载。
- 下载并发为 2；单个浏览器下载超过 120 秒会取消并报告超时。未完成的任务不会显示成功。
- 地址缺少扩展名且尚未读取时显示「未知格式」，尺寸未知时显示「尺寸未知」，无法估算体积时显示「体积未知」。指定格式筛选会排除不匹配的未知格式；尺寸 / 体积未知项保留，避免未读到元数据就丢弃候选。
- 关闭面板会结束其中的任务及 Blob 生命周期。需要长时间下载时使用独立标签页。

## 权限与隐私

无遥测、无后端、无外部脚本或运行时依赖，不上传图片或浏览记录。扫描及转换在本机执行。预览与回退下载可能访问原图片服务器。

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting` | 在用户打开面板、切换页面或重新扫描时读取页面图片；读取时按 documentId 定位原文档，避免页面导航后误用框架 ID |
| `http://*/*`、`https://*/*` | 访问跨域 iframe 及跨域图片；若收窄站点访问范围，对应来源可能不可用 |
| `debugger` | 短暂连接当前标签页，读取浏览器保留的原始图片资源；此权限必须在安装 / 更新时声明，不能作为运行时可选权限 |
| `downloads` | 保存文件并跟踪实际完成或中断状态 |
| `sidePanel` | 保持图片浏览和批量下载界面打开 |
| `storage` | 本地保存三个筛选阈值及按网站域名分组的 XPath、CSS 排除规则与图片忽略哈希，并同步已打开的面板 |

网页中有轻量的隔离世界观察脚本，仅监听页面图片变化，触发节流元数据采集以自动更新徽标。没有请求拦截、Cookie API 或页面主世界脚本。Debugger 仅在面板读取图片资源时短暂连接；页面脚本无法调用扩展的任意 URL 下载代理。

### 设置

点击图片库右上角齿轮打开设置页，也可以在 Chrome 扩展详情中打开扩展选项。设置按功能分类，「标题与文件夹 → 自动清洗标题」默认关闭。开启后去除网页原标题中的常见颜文字和 Emoji，同步用于标题和下载文件夹；保留普通括号内容及手动修改的标题。设置自动保存，对所有网站生效。

成功加载的图片预览右上角显示来源：绿色「浏览器资源」表示通过调试接口取得的原始图片字节，绿色「页面提取」表示页面像素、画布、内嵌数据或已有缓存，蓝色「URL 加载」表示通过图片地址读取。悬停可查看具体说明。标记反映实际预览来源；URL 加载可能命中浏览器缓存，实际下载仍优先读取原文件。加载中和失败的图片不显示成功来源标记。

「图片展示 → 优先展示成功加载的图片」默认关闭。开启后，成功预览排在加载中和失败图片之前，各组内继续按当前选择的页面顺序、面积或宽度排序。预览完成和重试成功后自动调整顺序，不隐藏失败项；关闭后恢复当前排序。

### 界面语言

设置页「语言 → 界面语言」提供「自动」、日本語、Deutsch、English、简体中文、繁體中文、한국어、Français。默认自动跟随浏览器语言，识别地区变体（如 zh-HK 使用繁体中文）；不支持的语言回退英语。手动选择会保存并同步更新已打开的图片库与设置页，切换时保留选择、搜索、网站规则输入及网页标题。翻译随扩展打包，离线可用。Chrome 扩展管理页中的名称与描述由 Chrome 根据浏览器语言显示。

多语言验证：`uv run --with playwright --with pillow python tests/language_test.py`，覆盖七种语言实时切换、自动识别、持久化与窄屏布局。翻译资源位于 `extension/locales/catalogs.js`；新增语言时需要保持键与占位符完整，并补充 Chrome 的 `_locales` 元数据。

### 明暗主题

设置页「外观 → 主题」提供「跟随系统 / 浅色 / 深色」，默认跟随系统。系统明暗模式改变时自动更新；手动选择浅色或深色后不受系统模式影响。设置自动保存并同步到已打开的图片库和设置页，切换不会重载预览或清空选择。主题覆盖卡片、筛选、表单、提示和底部下载区，图片与 Logo 保留原色。

主题验证：`uv run --with playwright --with pillow python tests/theme_test.py`。

已选数量显示在图片列表的全选开关右侧，仅有选中图片时显示；不再单独占用底部区域。预览加载失败的图片不能通过复选框、卡片点击或框选选中；已选图片若加载失败会自动取消选择，重试成功后可正常选择。

「URL 加载」表示预览使用图片地址，不等于重新联网下载。网页能显示跨域图片，不代表允许脚本导出像素；遇到跨域保护、批量预览预算或其他提取失败，悬停来源标记可查看具体原因。重试预览会先尝试已显示图片的像素和页面缓存；只有无法复用时才尝试 URL 请求。原文件下载仍优先保留原始字节与 GIF 动画。

开发版更新后，请在 `chrome://extensions` 的 ImageTaken 详情页点击「重新加载」，确认版本为 0.4.1。未打包扩展不会因磁盘文件改变而自动刷新已加载的 Manifest。后台控制台可用 `__imageTakenBadgeDiagnostics.get(tabId)` 查看最后一次自动计数状态、数量或失败原因。
