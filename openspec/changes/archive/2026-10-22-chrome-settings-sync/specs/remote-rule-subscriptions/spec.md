# Spec Delta

## MODIFIED Requirements

### Requirement: 管理多个远程规则订阅

系统 SHALL 在设置页独立分类提供添加、删除、逐项刷新与全部刷新，初始列表为空且不内置演示源。订阅在本机保存，按添加顺序排列，最多20项；开启配置同步时，只复制有序地址，不复制规则文档、刷新时间、错误或本机条目标识；重复地址不得重复添加。各项显示目标域名、源地址、最后成功时间和刷新状态，失败不报告成功。控件支持七种语言、明暗主题及320像素宽度。

#### Scenario: 添加多个订阅并重开
- **WHEN** 用户添加两个有效规则文件地址后重开设置页
- **THEN** 两项按添加顺序恢复，各自缓存和状态独立；刷新全部时单项失败不阻止其他项完成

#### Scenario: 删除尚在刷新的订阅
- **WHEN** 用户删除一个正在刷新的订阅
- **THEN** 其规则立即停止参与匹配，后续到达的旧响应不得重新创建订阅；不删除本地手动设置

#### Scenario: 无效或重复地址
- **WHEN** 输入重复地址、非 HTTP(S) 地址、含用户名密码的地址或不能识别域名的文件名
- **THEN** 阻止添加并显示具体原因，不创建伪成功记录；合法地址初次获取失败时保留可重试的错误项而不应用规则

#### Scenario: 采用另一机器的订阅列表
- **WHEN** 用户确认采用一个同步配置，其中有当前本机保留、新增或删除的订阅地址
- **THEN** 按确认顺序重建列表；相同地址复用本机缓存和条目标识，新增项在本机获取，删除项停止应用；旧请求不得复活已移除条目，其他机器的缓存或错误不导入
