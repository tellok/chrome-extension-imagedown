# Spec Delta

## MODIFIED Requirements

### Requirement: 徽标遵循当前过滤配置

系统 SHALL 在计数前应用顶层网站的 XPath、CSS 排除、忽略规则与搜索，以及当前尺寸、体积、格式、来源、加载状态和显示忽略项配置。同地址只计一次，不把规则已排除的候选加入计数。尺寸和体积 SHALL 使用源页面主机名（Hostname）解析的网站有效阈值：本地网站值优先，其次当前完整页面地址命中的远程对应值，最后宽高继承全局默认、体积使用 2048 字节；与图库保持一致。

#### Scenario: 原本成功显示的图片被规则排除
- **WHEN** 用户保存 CSS 排除规则或选择与图片不匹配的格式筛选
- **THEN** 这些图片从徽标计数中移除，关闭侧栏后仍遵循同一已保存配置

#### Scenario: 未展开时使用各网站阈值
- **WHEN** 两个源网站设置不同阈值，扩展视图均未打开
- **THEN** 各源标签页按自己的网站阈值计数，不套用另一网站的覆盖值

#### Scenario: 未展开时远程规则按路径生效
- **WHEN** 同一主机名两个页面命中不同远程规则，图库均未打开
- **THEN** 各源标签页按本地优先的有效配置计数，打开图库后不重置或切换计数来源


## ADDED Requirements

### Requirement: 订阅更新同步计数

系统 SHALL 在订阅添加、删除或有效规则变化时更新受影响页面的徽标，与图库使用相同完整页面地址、配置优先级及版本。只有普通筛选变化时复用已有候选；XPath或CSS变化时允许重新采集。仅刷新时间或错误信息变化不触发采集，旧配置或旧页面异步结果不得覆盖当前结果。

#### Scenario: 远程规则刷新与删除
- **WHEN** 远程阈值改变或用户删除生效订阅
- **THEN** 复用当前页面候选重新计算；删除后回退其他命中订阅或本地与全局默认，不为计数重新请求原图、导出像素或启动debugger

#### Scenario: 刷新失败保持计数
- **WHEN** 规则刷新失败且有效缓存仍存在
- **THEN** 继续按缓存规则计数，不因获取失败清零；无缓存时仅使用本地与全局默认
