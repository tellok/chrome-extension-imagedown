# Spec Delta

## MODIFIED Requirements

### Requirement: 默认阈值与普通筛选

系统 SHALL 以顶层网页主机名（Hostname）分字段保存最小宽度、最小高度和最小体积，不区分协议、端口或路径，不同子域名隔离。本地未覆盖字段先采用当前页面命中远程规则的对应值，再回退全局默认最低宽高（出厂值为 50 px / 50 px）及体积 2048 字节。没有订阅或没有命中时，沿用原有默认。低于任一阈值时隐藏，等于阈值时保留，未知尺寸或体积不因未知本身被隐藏。普通筛选支持图片地址（Uniform Resource Locator, URL）/ 描述搜索、格式、发现来源及页面加载状态。

#### Scenario: 阈值边界与未知数据
- **WHEN** 候选恰好达到阈值，或尚无可用尺寸 / 体积
- **THEN** 不因低于阈值而隐藏；后来获得元数据时重新应用筛选

#### Scenario: 保存与重置筛选
- **WHEN** 用户修改阈值、格式、来源、加载状态或显示忽略项
- **THEN** 阈值只保存到当前顶层网站并同步该网站视图，格式等其余选项仍按原有全局方式保存；阈值为 0 时取消对应限制

#### Scenario: 不同网站独立且同主机名复用
- **WHEN** 用户在一个网站保存三项阈值，再访问相同 hostname 的另一协议、端口或路径，以及不同子域名
- **THEN** 相同 hostname 恢复保存值，不同子域名按自己的配置解析；框架或图片服务器地址不决定阈值归属

#### Scenario: 未配置字段继承全局默认
- **WHEN** 没有对应远程值，用户只为网站保存宽度 0，全局默认宽高为 100 / 80
- **THEN** 网站有效阈值为宽度 0、高度 80、体积 2048 字节；保存宽度不会把其余继承字段固化为网站配置

#### Scenario: 全局默认变更只影响继承字段
- **WHEN** 设置页改变全局默认最低宽高
- **THEN** 未设置网站值且没有对应远程值的宽高实时采用新默认，已保存的网站值包括 0 保持有效，体积不受全局宽高修改影响

#### Scenario: 远程宽高与体积补充
- **WHEN** 本地只保存宽度0，当前页面命中远程宽度400、高度200、体积4096
- **THEN** 有效值为0 / 200 / 4096；本地0保持有效，远程字段不写成网站覆盖


### Requirement: 区分网站规则和普通筛选清除

系统 SHALL 在清除网站规则时只清除该域名的 XPath 与 CSS；清除普通筛选不更改网站规则或忽略记录，只将当前网站三项阈值保存为 0 并沿用其他普通筛选清除行为。恢复默认阈值 SHALL 删除当前网站的三项阈值覆盖，各字段重新继承当前命中远程对应值，否则宽高采用当前全局默认、体积恢复 2048 字节，不清除搜索记忆，不改其他网站或全局默认。

#### Scenario: 用户只恢复尺寸阈值
- **WHEN** 用户点击恢复默认阈值，没有命中远程阈值且全局默认宽高为 120 / 90
- **THEN** 当前网站宽高体积恢复 120 / 90 / 2048，已保存的搜索、网站规则与忽略记录保持有效；后续全局宽高变化继续生效

#### Scenario: 清除仅影响当前网站阈值
- **WHEN** 用户在一个网站清除筛选
- **THEN** 该网站三项阈值均为 0，其他网站的阈值与全局默认不变；清除搜索等现有普通筛选行为保持不变

#### Scenario: 清空本地规则和搜索覆盖远程
- **WHEN** 远程配置了XPath、CSS或搜索，用户主动清除对应本地内容
- **THEN** 显式空字符串作为本地覆盖保存，阻止同字段远程内容重新出现；清除普通筛选仍保存三项阈值0

#### Scenario: 恢复阈值采用远程默认
- **WHEN** 用户还原阈值且当前页面存在命中远程阈值
- **THEN** 删除对应本地覆盖后采用远程值，远程未配置字段才回退全局或出厂默认


### Requirement: 图库明确区分宽高继承和网站覆盖

系统 SHALL 在图库宽、高字段未单独配置时，以占位提示（Placeholder）显示有效继承来源：命中远程对应值时显示“远程默认({0})”，否则显示“全局默认({0})”，数值为对应来源的当前值；输入值本身保持空白。存在网站覆盖时直接显示数字，包括显式 0。是否继承 SHALL 由已保存配置决定，不能通过数值是否等于全局值判断。

#### Scenario: 网站未配置宽高
- **WHEN** 网站未配置宽高、没有命中远程对应值且全局默认为 50 / 80
- **THEN** 两项分别显示“全局默认(50)”和“全局默认(80)”，实际筛选采用 50 / 80，读取与显示不创建网站覆盖

#### Scenario: 覆盖值等于默认或为零
- **WHEN** 网站保存宽度 50、高度 0，全局宽度也是 50
- **THEN** 输入框显示数字 50 和 0，两项都仍属于网站覆盖，不显示继承占位文字

#### Scenario: 修改全局默认
- **WHEN** 全局默认改变
- **THEN** 继承字段的占位文字和有效阈值同步更新，已保存覆盖字段不变，不清空选择或重载成功预览

#### Scenario: 远程默认与来源
- **WHEN** 宽度继承远程400而高度回退全局80
- **THEN** 输入值均为空，占位分别为“远程默认(400)”和“全局默认(80)”；远程说明展示订阅文件及命中规则，长地址不撑宽输入框


### Requirement: 宽高可分别还原全局默认

系统 SHALL 在图库的宽、高输入框边框内部右侧各提供一个还原按钮，拥有对应维度的无障碍名称、键盘焦点及悬停说明。点击只删除当前网站该字段的覆盖并恢复继承，有远程对应值时继承远程，否则继承全局；名称和悬停说明须反映该来源；已继承时保留按钮位置并禁用。无网站、加载未完成或操作不安全时禁用，失败时显示错误并保留原覆盖状态。

#### Scenario: 只还原宽度
- **WHEN** 网站保存宽度 300、高度 120、体积 4096，用户点击宽度还原
- **THEN** 仅宽度恢复继承，高度仍为 120，体积仍为 4096，其他网站和全局默认不变；重开后继续继承宽度

#### Scenario: 只还原高度
- **WHEN** 用户点击高度还原
- **THEN** 仅删除当前网站高度覆盖，宽度和体积保留；既有“恢复默认阈值”仍可一次还原三项

#### Scenario: 单字段还原到远程
- **WHEN** 网站宽度覆盖为300且远程宽度为400，用户点击宽度还原
- **THEN** 仅删除网站宽度并显示“远程默认(400)”，其他字段不变；已继承时仍保留并禁用按钮
