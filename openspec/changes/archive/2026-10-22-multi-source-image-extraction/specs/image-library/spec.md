# Spec Delta

## ADDED Requirements

### Requirement: 图库呈现网站增强模式状态与入口

系统 SHALL 在列表内容末尾、包括空列表，显示当前源网站增强模式（Enhanced Mode）的入口。关闭时显示“没有找到需要下载的图片？试试增强模式”及仅对当前网站开启的说明；链接携带源标签页上下文，打开设置并滚动、聚焦网站开关。开启后替换为“增强模式已开启”、域名及关闭按钮，顶部同时用图标和文字标识；实际调试读取时才显示“正在增强提取”。

#### Scenario: 图片列表为空
- **WHEN** 有有效源网站但列表中没有符合条件的图片
- **THEN** 增强模式入口仍可见，不被空状态或下载区遮挡，打开设置时不把扩展页面当作源网站

#### Scenario: 用户直接关闭增强模式
- **WHEN** 用户点击列表底部关闭按钮且保存成功
- **THEN** 当前网站所有打开的图库更新状态；取消排队及进行中的自有调试工作，迟到结果不写入，保留已取得原图、有效选择和普通提取

#### Scenario: 用户取消浏览器调试提示
- **WHEN** Chrome 停止本次调试连接
- **THEN** 图库表达增强提取已停止，不把网站许可误显示为持续连接，也不在当前文档自动重连

### Requirement: 增强模式界面保持可访问与已有工作

系统 SHALL 在七种既有语言、明暗主题和 320 像素视图下呈现增强模式状态，不能仅靠颜色表达。开启成功触发一次增量扫描及未解决项重试，保留成功图片、有效选择、筛选、忽略及自定义标题，不自动下载；下载中延后新增扫描但关闭授权立即停止调试工作。

#### Scenario: 从设置页返回图库
- **WHEN** 用户开启当前网站增强模式
- **THEN** 图库自动补充发现和提取结果，无需整页重开，不清空原有选择；长域名和较长翻译不导致横向溢出
