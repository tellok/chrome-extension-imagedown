# Spec Delta

## ADDED Requirements

### Requirement: 已打开图库动态补充候选

系统 SHALL 在图库打开期间结合性能观察器（PerformanceObserver）、文档对象模型（Document Object Model, DOM）变化和图片加载状态，合并同一源文档的图片增量；覆盖可访问框架、换源及同地址复用。保留成功原图、有效选择、筛选与标题草稿，不自动滚动或创建网站尚未生成的图片。被动徽标仍仅使用页面元数据，不启动归档、图片请求或调试读取。

#### Scenario: 懒加载图片后来完成
- **WHEN** 用户在原网页展开内容，新增图片完成加载
- **THEN** 打开的图库补充候选并合并提取批次，不清空已有工作状态；页面导航后旧事件不更新新列表

### Requirement: 增强模式补充浏览器资源候选

系统 SHALL 仅在源网站已开启增强模式（Enhanced Mode）时，通过 Chrome 开发者工具协议（Chrome DevTools Protocol, CDP）的资源索引补充已加载但普通扫描未发现的图片，标明浏览器资源来源并保留所属文档溯源。新候选沿用范围、排除、去重、普通筛选及忽略规则。有范围约束而无法证明允许的资源不得加入。

#### Scenario: 资源没有对应页面元素
- **WHEN** 已授权网站的浏览器索引含普通扫描遗漏的已加载图片，且未限制采集范围
- **THEN** 将可验证所属文档的资源作为候选加入，不冒充有元素标题，不自动请求尚未加载的资源

#### Scenario: 浏览器资源落在排除范围
- **WHEN** 存在 XPath 或层叠样式表（Cascading Style Sheets, CSS）排除规则，资源不能对应到已允许元素
- **THEN** 不以增强模式绕过范围加入候选，已允许元素的同地址资源仅补充数据
