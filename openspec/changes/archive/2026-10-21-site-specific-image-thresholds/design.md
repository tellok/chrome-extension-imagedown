## Decisions

### 全局宽高是默认值，网站可单独覆盖

采用按字段继承，不采用强制全局下限或“改任一字段就固化三项”的快照。这样网站显式 0 有效，未配置字段能跟随全局默认变化。所有权由源网页主机名（Hostname）决定，协议、端口、路径不参与，不同子域名隔离，框架及图片来源不改变归属。

### 存储键与兼容

沿用 `filters:width`、`filters:height` 存全局默认，从而保留旧宽高而无需不可靠的数据复制迁移。网站覆盖使用 `filters:site:v1:<hostname>:width|height|minBytes`，分别写入独立键，防止不同输入或面板的读改写覆盖。最低体积只在网站键保存，旧 `filters:minBytes` 保留但不再参与有效阈值解析，缺省固定 2048 字节。没有来源信息的旧体积不归给首次打开的网站。

统一解析函数读取全局键及当前网站键，返回有效阈值；字段有效性检查须保留显式数值 0，缺失 / 无效保存值回退到对应默认。网站名必须来自 `siteDomain` 的规范化结果，不允许无网站上下文写空域名键。全局设置 UI 接受 0..100000 整数，空白不当作 0，保存失败保留旧值并反馈。

### 加载、同步和异步竞态

图库进入 / 切换源页面时，将三项阈值与网站规则、搜索一起读取，并在来源身份及 generation 校验后应用；删除初始化阶段先读全局值再扫描的路径。网站未知、扫描或读取尚未完成时禁用阈值写入，读取失败显示错误而不把临时默认值保存成网站配置。

捕获发起写入时的源域名，防止切换网站后将旧输入写到新网站。存储事件仅重读当前网站的有效值，忽略其他网站覆盖事件，必要时用独立修订号防止较旧读取覆盖用户刚输入或新域名的值。全局宽高变化只更新当前网站未覆盖字段；不重载原图、不清除选择，不打断正在编辑的无关字段。

后台 `loadThresholds(domain)` 使用同一解析器，存储监听区分网站键和全局宽高键：网站键刷新同主机名的源标签页，全局键更新可能受影响的网站，继续复用现有快照且不启动调试读取。不得让旧 `filters:minBytes` 再影响任何网站。

### 清除与恢复

清除筛选对当前网站三个字段写 0，搜索及其他选项清除沿用既有行为。恢复默认删除当前网站三个键，重新读取当前全局宽高及默认体积；后续全局修改继续继承。两操作不修改全局默认，也不影响其他网站。

### 设置与国际化

沿用分类设置页，新增数值控件并显示 px，按输入类型限制现有开关 CSS，避免新数值输入被画成开关；沿用现有主题变量。新增说明明确“未单独设置的网站使用默认值”，同步七种翻译。通过现有语言 / 主题回归覆盖 320 px 布局；不引入设计工具或运行库。

## Risks / Trade-offs

- 旧体积无法归属 → 明确采用新网站默认 2 KiB，在使用说明解释升级影响，保留旧键供代码回退。
- 跨域名输入与延迟读取竞态 → 每次异步应用校验域名和修订号；测试两域、多面板与异步失败。
- 用户误以为全局是强制下限 → 设置命名与帮助文案写明默认 / 覆盖关系。
- 新规则要求测试先审批 → 11 项完整清单见 `test-review.md`，审批前所有测试保持原样；发现新增需求先修订完整清单再确认。
