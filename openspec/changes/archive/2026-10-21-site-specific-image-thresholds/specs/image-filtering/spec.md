# 图片筛选变更

## MODIFIED Requirements

### Requirement: 默认阈值与普通筛选

系统 SHALL 以顶层网页主机名（Hostname）分字段保存最小宽度、最小高度和最小体积，不区分协议、端口或路径，不同子域名隔离。未覆盖的宽高继承全局默认最低宽高，出厂值为 50 px / 50 px；未覆盖体积使用 2048 字节。低于任一阈值时隐藏，等于阈值时保留，未知尺寸或体积不因未知本身被隐藏。普通筛选支持图片地址（Uniform Resource Locator, URL）/ 描述搜索、格式、发现来源及页面加载状态。

#### Scenario: 阈值边界与未知数据
- **WHEN** 候选恰好达到阈值，或尚无可用尺寸 / 体积
- **THEN** 不因低于阈值而隐藏；后来获得元数据时重新应用筛选

#### Scenario: 保存与重置筛选
- **WHEN** 用户修改阈值、格式、来源、加载状态或显示忽略项
- **THEN** 阈值只保存到当前顶层网站并同步该网站视图，格式等其余选项仍按原有全局方式保存；阈值为 0 时取消对应限制

#### Scenario: 不同网站独立且同主机名复用
- **WHEN** 用户在一个网站保存三项阈值，再访问相同 hostname 的另一协议、端口或路径，以及不同子域名
- **THEN** 相同 hostname 恢复保存值，不同子域名按自己的配置解析；框架或图片服务器地址不决定阈值归属

#### Scenario: 未配置字段继承全局默认
- **WHEN** 用户只为网站保存宽度 0，全局默认宽高为 100 / 80
- **THEN** 网站有效阈值为宽度 0、高度 80、体积 2048 字节；保存宽度不会把其余继承字段固化为网站配置

#### Scenario: 全局默认变更只影响继承字段
- **WHEN** 设置页改变全局默认最低宽高
- **THEN** 未设置网站值的宽高实时采用新默认，已保存的网站值包括 0 保持有效，体积不受全局宽高修改影响

### Requirement: 区分网站规则和普通筛选清除

系统 SHALL 在清除网站规则时只清除该域名的 XPath 与 CSS；清除普通筛选不更改网站规则或忽略记录，只将当前网站三项阈值保存为 0 并沿用其他普通筛选清除行为。恢复默认阈值 SHALL 删除当前网站的三项阈值覆盖，宽高重新继承当前全局默认、体积恢复 2048 字节，不清除搜索记忆，不改其他网站或全局默认。

#### Scenario: 用户只恢复尺寸阈值
- **WHEN** 用户点击恢复默认阈值，全局默认宽高为 120 / 90
- **THEN** 当前网站宽高体积恢复 120 / 90 / 2048，已保存的搜索、网站规则与忽略记录保持有效；后续全局宽高变化继续生效

#### Scenario: 清除仅影响当前网站阈值
- **WHEN** 用户在一个网站清除筛选
- **THEN** 该网站三项阈值均为 0，其他网站的阈值与全局默认不变；清除搜索等现有普通筛选行为保持不变

## ADDED Requirements

### Requirement: 旧全局阈值兼容

系统 SHALL 保留已有全局宽高作为新的全局默认最低宽高；缺失或无效值采用出厂值。旧全局体积没有网站归属，SHALL 不复制到任何网站，也不作为网站默认体积；旧数据保留以支持回退。

#### Scenario: 已保存全局筛选的用户升级
- **WHEN** 旧全局宽高为 320 / 180，旧全局体积为 8192 字节，当前网站未保存独立阈值
- **THEN** 网站有效阈值为 320 / 180 / 2048；已有全局宽高中的显式 0 也保留其取消限制含义

### Requirement: 阈值保存与读取失败可见

系统 SHALL 在阈值读取或保存失败时显示错误，失败读取不伪装成成功恢复；无有效顶层网站时不得写入网站阈值或覆盖全局默认。

#### Scenario: 没有网站上下文或存储不可用
- **WHEN** 当前网页没有有效 hostname，或本机存储读取 / 写入失败
- **THEN** 不创建空域名记录，读取失败时不以出厂值覆盖已保存配置，保存失败显示明确反馈且不报告保存成功
