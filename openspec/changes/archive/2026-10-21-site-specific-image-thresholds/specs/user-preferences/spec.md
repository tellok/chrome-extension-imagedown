# 用户设置变更

## ADDED Requirements

### Requirement: 全局默认最低宽高设置

系统 SHALL 在设置页的“图片筛选”分类提供全局默认最低宽度、最低高度，单位为像素（Pixel, px），出厂值均为 50。配置在本机自动保存并在重开后恢复。全局值只为没有对应网站覆盖值的字段提供默认值，不是强制下限；设置页 SHALL 清楚说明这一边界及网站最低体积默认 2 KiB，不增加全局体积设置。

#### Scenario: 未配置过网站的初始阈值
- **WHEN** 用户设置全局默认宽度 200、高度 100 后打开一个未配置网站
- **THEN** 图库与工具栏计数采用 200 / 100 / 2048 字节，重新打开设置页仍显示 200 / 100

#### Scenario: 同网站已有单独设置
- **WHEN** 用户修改全局默认最低宽高，一个已打开网站分别保存了宽度 0 和高度 20
- **THEN** 该网站继续采用 0 / 20；仅未覆盖相应字段的网站实时采用新默认

### Requirement: 全局宽高输入有效性与错误反馈

系统 SHALL 接受 0 至 100000 的整数宽高，0 表示默认不限制该维度；空白、负数、非数值、小数及超出上限的输入不得覆盖最后成功保存的值，且提供校验反馈。保存或读取失败 SHALL 显示错误，不报告成功；初始读取失败时不得允许误写覆盖现有配置。

#### Scenario: 无效输入与保存失败
- **WHEN** 用户提交无效宽高，或有效宽高无法写入本机存储
- **THEN** 原已保存值保持不变，界面说明输入或保存错误；有效输入保存成功后才显示成功反馈

### Requirement: 全局宽高沿用界面语言与主题

系统 SHALL 为全局宽高设置及网站阈值继承提示提供既有七种界面语言，沿用当前明暗主题和窄屏布局；设置变化不重载已成功加载的图片、不清空选择或未保存的网站规则。

#### Scenario: 窄屏和多视图设置更新
- **WHEN** 用户在设置页修改全局宽高，并切换界面语言或明暗主题
- **THEN** 新控件及提示正确翻译并保持可用，不超出 320 px 宽度；图库仅更新适用字段及筛选结果，保留已加载图片数据和用户工作状态
