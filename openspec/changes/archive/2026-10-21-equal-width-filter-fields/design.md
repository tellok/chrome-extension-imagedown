# 等宽筛选控件设计

## Context

基线为 `ea3a56f`。按截图、dimension-control、input ID、等宽 / 还原及测试几何断言检索，完整阅读 image-filtering 主规格和前次 gallery-threshold-reset-controls 的 proposal、design、delta、tasks；核对 image-library 响应式约定、panel 样式和相关测试。当前代码与主规格“按钮在外部右侧”一致；此次根据用户新反馈显式改变位置，不静默修正既有规范。

开始时 main 工作区干净，默认分支为 origin/main，活跃 change 清单为空；无继承 change，本次唯一新建 equal-width-filter-fields。首次产品改动前判定 OpenSpec: required；目标为 panel HTML / CSS、一项测试与必要说明，当前仅规划。

## Goals / Non-Goals

让相同网格列的输入 / 选择控件可见边框等宽，保持原有交互、数据、主题和 Notion 风格。不同跨度的控件（例如窄屏下独占整行的来源下拉）按自身跨度布局，不强行与半行控件同宽。不改变阈值逻辑或设置页。

## Decisions

宽高输入框占满所在列，输入组作为定位容器，将还原按钮放在边框内右侧，为 px 单位和按钮分配独立区域；文本内边距避开两者。按钮不再占外部弹性宽度。不为其他控件增加无意义的按钮留白，也不移除还原功能。沿用现有图标和颜色变量，保留焦点及 disabled 状态。

在 320 px 两列与 900 px 五列、明暗主题下，比较宽、高、体积、格式四个等跨度控件实际边框宽度，允许至多 1 px 渲染误差，同时检查按钮被包含、单位不相交及页面不溢出。长占位提示仍可截断，通过原有完整悬停说明查看；数字输入和还原行为断言保留。

## 风险与审计

- 内部按钮挤压文本或单位 → 为两者预留独立右侧区域，窄屏及较长语言验证。
- 仅使外层等宽仍保留内部边框缩短 → 测量真实 input / select 的边框，不只比较容器。
- 旧测试要求按钮位于框外 → 明确更新同一个用例的几何断言，详见 test-review.md，审批前不编辑测试。

External-Skill: exempt：检查包、打包清单、skills 目录与文档，无对外技能或误置入口，内部维护技能不受本次视觉改动影响。README-Glossary: verified：主规格、README 和历史归档均无本次涉及的私域术语变化；等宽 / 网格 / 边框为通用概念，保留原空术语表。未启用 Changesets。
