# 图库宽高输入与单项还原设计

## Context

动机见 proposal。本次在提交 `1d4b551` 的网站阈值功能上补充图库交互。当前 `applyThresholds` 将有效宽高写入输入值，`filters()` 直接转换输入值，导致仅将数字换为空白占位会意外解除限制。`resetThresholds` 目前删除三项键，不能用于单项按钮；图库在主题样式中已有输入边框、按钮、焦点及图标体系。

首次产品文件修改前判定：`OpenSpec: required`。目标为 panel HTML / CSS / JS、preferences、翻译与文档 / 已批准测试。当前阶段只写规划，不改业务代码、测试或主规格。

## Goals / Non-Goals

保证视觉上的“空输入继承”与实际筛选一致，逐字段删除覆盖，不改变原有主机名（Hostname）隔离、全局配置及徽标规则。仅限制图库宽高编辑，不改变最低体积的小数输入、设置页、图片预览来源或下载功能。

## 阅读与流程审计

## Decisions

### 同时持有有效值和配置来源

preferences 提供一次存储快照解析出的有效值、全局默认和网站覆盖状态，保持现有 `loadThresholds` 对后台的数值接口。图库使用有效值进行过滤，独立使用覆盖状态控制 value、placeholder 和按钮。不能以 `Number('')` 或 placeholder 文本计算阈值，也不能以“数字等于默认”推断继承。

复用域名 / 修订号保护，避免跨源网页的异步响应写错界面。全局变化更新继承提示，手动编辑和显式 0 保持。配置事件不重建已成功预览，不丢选择或未保存规则。

### 外部右侧图标按钮

在宽、高各自的字段中使用输入组：数字框、px 单位、小尺寸还原按钮。按钮使用本地现有线条图标或同体系矢量，不使用彩色图案或实心主按钮。中性色、小圆角、细边框与现有字号保持一致；保留键盘焦点框和完整悬停 / 无障碍描述。没有覆盖时禁用但不隐藏，减少布局跳动。长占位文字不挤压单位和按钮，完整内容保存在可访问说明中。

### 单项删除与原三项恢复并存

新增或扩展内部删除函数，使单项还原只操作当前域名的一个键；原恢复默认按钮仍删除三键。点击时捕获域名，成功后重新解析配置再显示继承；失败显示错误并保留覆盖。已继承、无域名、加载中或下载占用时禁用还原按钮。不会覆盖全局默认，也不把有效数值再次写为网站覆盖。

### 数字输入与空白草稿

使用文本型输入配合数字键盘提示 `inputmode=numeric` 与数字模式，避免原生数值框允许 e、正负号及小数。通过编辑事件校验键入、粘贴、拖入和输入法提交，不采用“移除非法字符再保存”的转换；可用编辑 / 选择快捷键不拦截。

合法数字按既有自动保存路径写入，0 是有效覆盖；空白仅为正在编辑的草稿，过滤继续沿用最后有效配置，失焦恢复配置显示。超出 100000 的数字不保存并提示。清空不自动还原，避免退格中间态意外更改网站配置；还原由明确按钮执行。

### 国际化和测试调整

新增动态占位“全局默认({0})”与各维度还原说明，完整更新既有七种语言目录及占位符。自动化中继承字段改为断言空 value、对应 placeholder 和真实筛选结果；不能只删除旧数字断言而失去行为覆盖。需要改动的完整 5 项测试见 test-review.md，未获批准不得编辑。

## Risks / Trade-offs

- 空文本被当作 0 → 过滤使用独立有效数值，不从继承显示推断。
- 两个相同数值实际来源不同 → 从网站键是否存在 / 有效判断，显式 0 和等值覆盖都保留。
- 新按钮挤压窄屏 → 弹性输入组、按钮固定尺寸、长文说明及七语言 / 明暗回归。
- 部分重置或失败误删其他键 → 定向单元及浏览器验证键范围、持久化和错误反馈。

## Migration Plan

无存储迁移。审批后实施状态解析、控件和五项确认测试，运行基础 / 浏览器 / 徽标 / 语言 / 主题验证，同步文档与主规格，归档后按 AGENTS 自动提交，不自动推送。回退只恢复旧图库显示和三项恢复入口，既有网站及全局数据格式保持兼容。
