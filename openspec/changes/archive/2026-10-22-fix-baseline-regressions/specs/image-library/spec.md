# 图库规格增量

## ADDED Requirements

### Requirement: 取消最后选择可靠释放原页高亮

系统 SHALL 在图库取消最后一个实际选择后，于正常可见页面中一秒内移除该图库持有的原页红框，不因更新与连接关闭交错而等待异常失效周期。其他图库仍持有的选择继续高亮；已释放会话的迟到更新不得恢复旧标记。释放不改变网站样式、布局或交互，不发起图片请求。

#### Scenario: 最后选择取消且连接关闭
- **WHEN** 图库取消最后一个选择，随即关闭本视图的高亮连接
- **THEN** 本视图会话被释放，若没有其他视图选择则一秒内清除全部红框和绘制任务

#### Scenario: 另一视图仍有选择
- **WHEN** 两个图库选择同一图片，其中一个取消最后选择或关闭
- **THEN** 原页保留另一个图库持有的高亮，直到最后一个持有者释放，不接受已结束视图的迟到更新
