# Design

## Context

动机与范围见 [proposal.md](proposal.md)。当前 `3c7bdc4` 的图库状态为内存中的 `state.selected`；`selectionUI` 汇集卡片、复选框、全选及 `bindGallerySelection` 的变化。`scanTab` 以完整地址合并候选，以 `{documentId, frameId, id}` 保留跨文档读取入口。采集器按地址仅保留一个 `element`，后续同地址可能替换该引用，因此不能直接拿现有字段证明全部对应元素。`sourceReference` 只有标签与可选 id，是溯源描述，不是可靠选择器。

## Goals / Non-Goals

**Goals:** 在现有选择语义下，稳定、可清理地将图库候选映射到原页现存元素；任何过期任务不能恢复旧高亮；保持页面交互、样式、采集与下载行为。

**Non-Goals:** 不添加设置或开关，不自动滚动/聚焦原页，不进入关闭的 Shadow DOM 或受保护页面，不为尚未扫描的新节点猜测位置，不改变图片读取及配置同步格式，不增加第三方服务、权限、依赖或运行进程。框架内绘制受框架可视区域裁剪；不承诺跨越浏览器顶层界面、全屏顶层元素或其他页面覆盖层显示。

## Decisions

### 1. 元素映射在原文档内保存

采集记录保留独立于原文件读取 `element` 的元素出现集合，按引用去重。重复地址的每次 add 都补充出现项；保存来源类型和验证所需完整地址，`picture > source` 映射到所属 img。CSS/伪元素标记宿主，Canvas/SVG/封面/链接标记各自元素。对响应式和懒加载地址，当前来源声明仍包含该候选即可匹配，无需强迫 currentSrc 相同；普通 img 的旧地址被全部替换后失效。

元素引用不经 Chrome 消息序列化，不写 storage；传输仍用文档 id 和采集记录 id，不向页面主世界公开选择详情。首次来源元数据和既有读取入口保持不变。最近三次扫描历史仍用于读取；活动高亮会话持有自己已解析的元素集合，不能因另一图库扫描挤出历史而丢失既有标记。视图重新扫描后替换该会话集合，不积累旧记录。纯资源记录无元素则无高亮。

替代方案仅按 URL 临时全页 query 会遗漏开放子树、误标扫描范围外图片并造成重复遍历；sourceReference 字符串不能唯一定位，因此不用。

### 2. 每文档一个绘制器，元素样式不改写

新增本地打包 `source-highlights.js`，由已有脚本注入能力在目标文档中初始化。每文档最多一个临时宿主，内部使用封闭 ShadowRoot 隔离样式；宿主固定定位、零布局占用、不可聚焦、aria-hidden，宿主及子节点均 `pointer-events:none`。每个实际目标一个矩形，使用 `border:2px solid #ff0000`、border-box，以元素 `getBoundingClientRect()` 的轴对齐范围贴合；不改网站 border/outline/style/class，不包裹元素。

不使用修改原元素 outline 的方案，避免覆盖网站焦点轮廓或与网站自身属性写入互相回滚。临时覆盖层本身是可完全移除的扩展节点，不承诺页面永远没有临时节点。

仅有活动目标时运行合并后的 requestAnimationFrame（动画帧调度），批量读取几何后批量写入变动矩形；无变化不重复写属性。滚动、缩放、CSS 动画、布局变化可跟随。不可见、断开连接、没有可见矩形或来源已变的目标不绘制；最后一个活动目标/会话释放后撤销循环、定时器和宿主。页面生命周期事件清理，恢复时只接受仍有效的会话更新。普通可见页面选择更新目标为 1 秒以内；浏览器后台冻结不能承诺墙钟实时性。

采集器明确跳过覆盖层宿主及其子树；`badge-observer.js` 仅忽略全部由该宿主内部绘制引起的变更，混有真实网页变更时仍通知。这样不会从 overlay 中采集伪图片，也不会形成每帧徽标扫描回路。高亮不请求图片、读取像素或附加 debugger。

### 3. 视图会话、序号与文档隔离

新增 `selection-highlights.js` 作为图库侧薄客户端、`source-highlights-background.js` 作为后台协调器。`panel.js/selectionUI` 提交全部仍选中的 items，而非仅 visible；仅选集/映射/源文档变化时发送，框选变更在动画帧内合并，最多保留最新待发快照，避免按每张图重复注入。后台按 documentId 分组，一次更新一个文档；单个文档失败单独处理。

复用 runtime.connect 的端口生命周期模式，但采用独立端口名与会话，不改徽标端口协议。仅接受本扩展 `panel.html` 的连接；后台签发会话 id，消息校验 tabId、documentId、记录 id 及递增序号。后台将操作串行化并在异步注入前后检查会话仍活动且序号最新。源文档同样保存每会话最后序号，拒绝延迟旧包；结束会话具有终止语义，不能由迟到消息复活。

多个会话按元素引用合并绘制。会话 A 取消仅移除 A 的引用，B 持有则仍绘制；不同候选共用元素也只显示一个框。源标签导航/切换先释放旧文档，再提交新映射；只以 `documentIds` 注入，不仅凭 frameId 或 URL 猜测新文档。结构范围更新保留的选择需要提交新 origins，即使 key 未变也不能省略更新。

### 4. 清理与异常回退

正常取消、refresh 清空、源页切换、loading 导航、tab removed、pagehide 和端口 onDisconnect 发送有序释放，不只依赖 unload 异步任务。后台释放后不再接受旧会话写入；源页去框无须等待扫描、预览或下载结束。

源页会话增加 15 秒无续期失效的安全兜底。只在非空选集存在时每 5 秒发会话续期，续期只更新时间，不重新注入/解析全部元素；最后一个会话失效清理覆盖层。后台或扩展异常中断时可在页面恢复执行后的下一次失效检查清理。端口重连重新建会话并提交完整当前状态，旧会话只能被释放或超时，不能覆盖新会话。页面隐藏不主动取消用户选择；浏览器冻结后的计时语义不声称固定墙钟期限。

访问失败、文档消失或权限撤销时吞并本功能的预期失效结果，保留可诊断日志，不影响选择/读取/下载，也不新增误导性的下载错误。后台验证拒绝页面脚本伪造消息，不暴露可远程执行任意注入函数的通用接口。

### 5. 验证与文档

拟新增 4 项协调单元测试及 12 项真实扩展浏览器测试，逐项见 test-review；原 85 项单元及既有浏览器脚本、断言、超时、夹具不改。新浏览器脚本自带临时网页、临时配置、HTTP 服务和 CHROMIUM_PATH 支持；不复用会掩盖启动错误的既有远程规则 session。CI 在原四个脚本之外新增专项入口，不删除或放宽任何原检查。

浏览器用真实选择操作、DOM 几何/事件/computed styles、页面及后台错误监听、截图、请求计数验证。不用单纯查询内部状态证明红框可见；至少目视核对红色/宽度和重复图片、框架、滚动截图。功能截图是运行后证据，无需引入设计工具或修改设置 UI。

README 在选择说明中补一条原页红框与取消规则；开发文档记录映射、会话与清理、兼容边界及专项命令。不更改产品版本和 Manifest 权限，无 Changesets 配置，不引入该工具。

## Risks / Trade-offs

- 任意网站可能遮挡/移除覆盖层 → 仅在活动会话重建扩展自己的临时宿主，不修改网站样式；受浏览器保护内容不承诺高亮。
- 大量重复元素产生几何开销 → 以元素去重、仅遍历实际选中目标、每文档批量读写、无选集停止；不得增加全页轮询扫描或截断原有候选。
- 续期受后台节流影响 → 正常关闭走端口释放，失效定时为异常兜底；恢复时完整重报当前选择，不把过期红框视为永久网站修改。
- 覆盖层加入可能触发观察器 → 专门排除本功能自生变更，测试同时验证真实图片变更仍计数。
- 管理员策略和下载网络限制 → 实施后浏览器检查必须在获准的开发浏览器完成；不得绕过策略、跳过断言或在未运行时归档为完成。

## Migration Plan

无存储迁移，所有元素/会话/高亮只在当前文档和运行上下文存在。审批 proposal、两份 delta、design、tasks 和全部 16 项测试后进入 Apply；按映射→绘制→协调→图库接入→验证顺序实施。验证通过后同步两份主规格，按既有归档技能归档、运行提交门禁并自动提交；不自动推送。回退或升级使旧连接失效，清理或租期兜底释放旧覆盖层。
