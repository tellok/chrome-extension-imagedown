# Spec Delta

## ADDED Requirements

### Requirement: 图库选择同步原页高亮

系统 SHALL 在侧栏或独立图库选择图片时，为源页面中可匹配的现存元素显示红色、2 CSS 像素宽的边框式高亮，支持多张同时选中。卡片、复选框、键盘、全选和框选必须使用同一实际选择状态，取消选择或因失败、忽略及范围变化被移除的选择必须及时移除对应高亮；仅被普通筛选隐藏而仍选中的图片保持高亮。正常可见页面中，选择或取消后 1 秒内更新，不依赖额外页面扫描或图片请求。

#### Scenario: 多选及逐项取消
- **WHEN** 用户选择两张图片，再取消其中一张
- **THEN** 两张先分别显示红色 2px 框，取消项及时去框，另一张保持高亮

#### Scenario: 框选被取消
- **WHEN** 用户框选或反选后按 Esc 恢复手势前的选择
- **THEN** 原页高亮随恢复后的实际选择更新，不保留临时框选结果

#### Scenario: 筛选隐藏或实际取消
- **WHEN** 普通筛选隐藏仍选中的图片，随后取消可见列表全选
- **THEN** 隐藏选择继续高亮，仅实际被取消的选择去框；预览失败或忽略导致自动取消时同样去框

### Requirement: 原页高亮不干扰页面

系统 SHALL 让高亮不占据页面布局空间、不拦截鼠标、触摸或键盘交互，不改写网站原有边框、轮廓、事件或图片属性，不包裹或重排网站元素；滚动、缩放和元素尺寸或位置变化后跟随目标。目标隐藏、移除或已改为其他资源时不继续标记错误位置。高亮不得参与图片采集或制造持续徽标扫描，不读取像素或混淆完整原文件与静态像素缩略图。

#### Scenario: 带有既有样式的图片位于链接中
- **WHEN** 用户选中有原有边框和轮廓的链接图片，滚动并调整窗口大小后取消选择
- **THEN** 高亮跟随图片且点击仍到达原链接，图片与相邻元素尺寸位置不因高亮改变，网站样式完整保留

#### Scenario: 页面动态移除目标
- **WHEN** 网站隐藏、删除或更换所选图片的资源
- **THEN** 高亮不留在旧坐标，不误标替代图片；仍保留其选择不代表已匹配新的页面元素

### Requirement: 原页高亮按视图与文档清理

系统 SHALL 按图库视图及源文档隔离选择高亮，多个活动视图对同一页面显示选择并集。刷新清空选择、切换源页、导航、关闭图库或源页后清理失效标记和本功能临时资源；关闭一视图不影响另一视图仍持有的选择。旧文档、过期选择及已关闭视图的异步更新不得重建高亮。页面访问失败或失去权限时保持图库可用，不把高亮失败显示为下载失败，也不绕过浏览器访问控制。

#### Scenario: 两个图库选择同一图片
- **WHEN** 侧栏与固定源页的独立图库都选择该图片，随后侧栏取消选择或关闭
- **THEN** 独立图库仍持有选择时保留原页高亮，最后一个视图释放后清理

#### Scenario: 页面导航与延迟更新交错
- **WHEN** 原页导航或图库切换来源时，旧选择更新尚未完成
- **THEN** 新页面不出现旧图片标记，旧更新不能重建已释放的高亮

#### Scenario: 关闭视图或扩展连接异常
- **WHEN** 所有持有选择的图库关闭或其连接失效
- **THEN** 普通关闭及时移除全部临时标记；异常中断后通过有界失效清理，不永久遗留页面改动

#### Scenario: 个别框架拒绝访问
- **WHEN** 某个来源框架被浏览器拒绝访问
- **THEN** 该框架不显示虚假高亮，其他可访问目标照常更新，图库选择、预览和下载仍可继续
