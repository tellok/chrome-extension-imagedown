# 高级功能区块定位规格增量

## MODIFIED Requirements

### Requirement: 图库呈现网站增强模式状态与入口

系统 SHALL 在列表内容末尾、包括空列表，显示当前源网站增强模式（Enhanced Mode）的入口。关闭时显示“没有找到需要下载的图片？试试增强模式”及仅对当前网站开启的说明；链接携带源标签页上下文，打开设置并在核实来源后滚动、聚焦“高级功能”整个区块，以完整边框高亮定位目标，不自动聚焦网站开关。区块失去焦点时恢复普通边框；普通设置入口不自动聚焦或高亮该区块。高亮沿用明暗主题，保持区块尺寸不变、不闪烁，并保留开关原有的键盘焦点提示。开启后替换为“增强模式已开启”、域名及关闭按钮，顶部同时用图标和文字标识；实际调试读取时才显示“正在增强提取”。

#### Scenario: 图片列表为空
- **WHEN** 有有效源网站但列表中没有符合条件的图片
- **THEN** 增强模式入口仍可见，不被空状态或下载区遮挡，打开设置时不把扩展页面当作源网站

#### Scenario: 用户直接关闭增强模式
- **WHEN** 用户点击列表底部关闭按钮且保存成功
- **THEN** 当前网站所有打开的图库更新状态；取消排队及进行中的自有调试工作，迟到结果不写入，保留已取得原图、有效选择和普通提取

#### Scenario: 用户取消浏览器调试提示
- **WHEN** Chrome 停止本次调试连接
- **THEN** 图库表达增强提取已停止，不把网站许可误显示为持续连接，也不在当前文档自动重连

#### Scenario: 从增强模式入口定位整个高级功能区块
- **WHEN** 用户点击图库末尾的增强模式入口，设置成功核实源网站并读取授权状态
- **THEN** 高级功能区块成为焦点目标并滚动至可见位置，标题、域名、开关和说明由同一个高亮边框包围，开关不自动获得焦点，授权值不因跳转改变

#### Scenario: 用户继续使用键盘操作开关
- **WHEN** 区块已获焦点，用户按 Tab 移到网站开关
- **THEN** 区块恢复普通边框，开关具有正常的键盘焦点提示，并能用空格切换；高亮变化不引起布局位移

#### Scenario: 普通设置入口及无效来源
- **WHEN** 用户普通打开设置，或增强模式入口的源网站校验或授权读取失败
- **THEN** 不自动聚焦或高亮高级功能区块；无效来源和读取失败沿用原有的开关禁用与错误提示，不因视觉定位绕过校验
