# Spec Delta

## MODIFIED Requirements

### Requirement: 本机处理与最小数据存储

系统 SHALL 使用本地打包的代码、翻译与素材，无运行时外部脚本、遥测或自有后端，不上传图片或自动收集浏览记录。偏好和网站规则在本机生效；本机同步开启时，允许通过Chrome同步明确范围内的配置，包括搜索词、网站域名、订阅地址和忽略摘要。忽略规则仍只持久化内容摘要，不持久化原图片地址或Base64；目录授权、图片与运行缓存不得同步。

#### Scenario: 使用预览与下载回退
- **WHEN** 完整数据尚不存在于扩展，需要按图片 URL 读取
- **THEN** 可访问原图片服务器，但不把图片转交给额外分析或存储服务；本地原图缓存随其列表生命周期释放

#### Scenario: 开启或关闭配置同步
- **WHEN** 用户使用默认开启的Chrome配置同步，或在当前机器关闭
- **THEN** 开启仅向Chrome同步允许配置，文档明确说明范围与浏览器依赖，设置行保持简洁；关闭停止新同步请求并继续本地使用，不新增自有上传服务
