# Design

## Context

当前main为3c7bdc4，已推送，活动清单初始为空；本change是唯一新建项。用户要求同步界面只表达本机是否开启，以及有冲突时如何选择。

已完整读取settings-sync、user-preferences、extension-platform主规格，以及2026-10-22-chrome-settings-sync归档的proposal、design、相关delta与tasks。按sync-status/sync-retry/sync-conflict、配额、状态投影及预计路径检索源码和测试。3c7bdc4的settings.html常驻两段说明与检查按钮，settings-sync-ui.js将checking、disabled、equal、pending、conflict、waiting-data、error全部渲染成可见文案；后台和UI契约一致，本次显式修改其展示要求。

读取settings-sync.js、设置页绑定、settings.css、七语言目录、docs/settings-sync.md、README与开发说明；测试盘点覆盖全部tests、脚本、打包与CI，见[test-review](test-review.md)。不重写旧归档，也不改后台格式来实现UI精简。

## Goals / Non-Goals

**Goals:** 日常只有本机开关；只有真正待决冲突才展示版本选择。用户主动操作有明确失败反馈，不把内部状态当作开关是否生效。

**Non-Goals:** 不新增账户检测、权限或依赖，不改同步默认值、每机隔离、配置范围、分片、配额、因果比较、重试或原图/下载策略；本轮只规划。

## Decisions

### 常态为单行开关

保留“配置同步”分类及“在此机器同步配置”开关，开关本身表达参与状态，不另加“已开启/已关闭”重复说明。不保留原范围说明、Chrome依赖、成功/等待诊断或常驻重新检查。底层ready/busy继续禁用不安全操作，不把checking当作关闭，也不将开关等同于云端送达成功。选择此方案以符合用户明确要求，不增加折叠的高级状态面板。

### 冲突才出现处理区

state为conflict时显示“本机与同步的配置不一致，请选择要使用的设置。”及“使用本机设置”“使用同步设置”“查看差异”。差异默认收起，原分组、显式空/0/false/未设置、长值、安全文本与展开状态保留。单候选无需随机设备标识与额外版本标题；多候选用“同步版本 {0}”和时间区分，仍将真正revision传给后台，不能用展示序号替代决策令牌。编号只是展示，不代表优先级或自动胜者。

冲突解决后收起，新的并发分支仍按后台结果重新提示；图库原有仅冲突提示入口保留。无需常驻展示所有设备编号或时间线。

### 技术诊断与操作反馈分离

后台状态、自动重试、错误原因仍保存供排查，UI不将ready=true的自动失败变为常驻提示。同步范围、账户/扩展ID依赖、配额及故障处理留在docs/settings-sync.md，文档删除“设置页显示写入成功”“点击常驻重新检查”的过时描述；不新增设置内的技术说明入口。

读取初始化失败、用户主动切换开关/选版本/按需重试失败时，仅给简短反馈，如“操作未完成，请重试。”和此时才出现的“重试”。不显示Chrome原始错误或存储术语，不把失败误报成功。初始化未完成仍禁用修改，可通过重试恢复读取。

UI将操作反馈单独保存，不把展示错误写回后台的冲突状态或抹掉最新候选。重试调用已有retry重新比较，不能自动重放失败的选择令牌；若需要选择，重新给出最新候选。操作恢复后移除反馈及重试。普通后台事件不自行弹出操作错误。

### 实施范围与兼容

仅修改settings.html、settings-sync-ui.js、settings.css、locales/catalogs.js及同步说明；其余文档如需准确复述才同步。旧翻译键若后台仍用就保留，不为了清理文案改后台错误格式。保持七语言、明暗中性色Notion风格、320px与键盘/读屏访问。后台、持久化、时序和权限不改，无数据迁移。

测试只修改SB02、SB03、SB05、SB12并新增SB13；无共享夹具或其他用例修改。SB12用现有内部状态与自动发布验证恢复，不保留无用按钮来满足旧断言。SB05沿用七语言两主题，新增展示检查与截图；SB13用用例内消息失败夹具验证简短反馈和安全重试。

## Risks / Trade-offs

- 自动故障不再在设置行可见 → 用户明确要求精简；保留后台诊断、自动重试和完整使用文档，不将开启显示为已送达。
- 精简候选标签造成无法区分版本 → 多候选保留编号与时间以及逐项差异，实际revision及过期保护保持原样。
- 旧测试依赖被移除的成功文案/常驻按钮 → 明确调整4项并新增1项，保持全部存储、冲突和恢复断言，不放宽安全检查。
- 初始读取或用户操作失败后无路可走 → 简短提示与仅失败时出现的重试，未就绪禁止覆盖。

## Migration Plan

批准当前提案和5项测试变更后实施；无需迁移存储。完成85项现有单元、新旧同步浏览器与相关设置/语言/主题回归，检查截图与文档链接；同步三份delta、严格校验、归档及本地自动提交。不自动推送；可通过回退界面提交恢复旧展示，不更改后台数据。
