# image-discovery Specification

## Purpose

规定 ImageTaken 如何发现当前网页的候选图片，使已显示资源与暂时无法读取的地址都能被识别，并明确跨框架、重复地址、懒加载及浏览器受限内容的发现边界，供后续读取和筛选使用。

## Requirements

### Requirement: 区分发现与读取

系统 SHALL 将候选图片发现与图片数据读取分开，读取失败不能使已发现的候选从列表消失。

#### Scenario: 地址过期但页面仍有图片
- **WHEN** 页面引用了图片，而扩展重新读取该地址失败
- **THEN** 图片候选仍保留，并在预览失败时提供失败状态和重试入口

### Requirement: 支持多种页面图片来源

系统 SHALL 发现图片元素的当前地址、src、响应式候选、常见懒加载地址，以及 CSS 背景、遮罩、边框、列表与伪元素图片；同时支持 Data URL、Blob、Canvas、内嵌 SVG、SVG image、视频封面、图片链接和图片资源记录。

#### Scenario: 页面使用多种图片承载形式
- **WHEN** 当前文档同时包含普通图片、背景图片、画布及视频封面
- **THEN** 扩展收集各自的候选，并标记发现来源，不只收集 img 标签

### Requirement: 访问开放子树并按地址去重

系统 SHALL 遍历开放 Shadow DOM 和有访问权限的 iframe，对相同图片地址合并来源与可用读取入口；不同 Canvas 保持独立候选。

#### Scenario: 同一图片出现在不同框架
- **WHEN** 主文档和可访问 iframe 引用了同一完整图片地址
- **THEN** 列表只显示一个地址候选，同时保留各文档的读取入口

### Requirement: 按当前内容扫描

系统 SHALL 仅采集当前存在的 DOM 和仍可查询的资源记录，不自动滚动网页或创建尚不存在的懒加载内容；无法访问关闭的 Shadow DOM 或受保护框架时不得宣称已采集其中内容。

#### Scenario: 图片需要滚动后才创建
- **WHEN** 图片元素尚未由网站创建
- **THEN** 扩展不保证发现该图片，用户展开或滚动网页后可重新扫描

### Requirement: 保存图片采集时的溯源信息

系统 SHALL 为图片保留采集页面完整地址、图片原标题、采集时间及可用来源引用。原标题优先取元素非空 title，其次 alt，再取内嵌 SVG 的 title；未提供时明确缺失，不用文件名或页面标题冒充。时间使用带 UTC 时区的 ISO 8601 格式，表示采集时刻，不以下载时刻替代；无元素的资源记录仍有所属文档地址和采集时间。

#### Scenario: 图片来自框架或仅有资源记录
- **WHEN** 图片在 iframe 中发现，或只存在于浏览器资源记录
- **THEN** 分别记录对应框架文档或资源所属文档的地址，不一律使用顶层页面地址，无法取得原标题时明确缺失

#### Scenario: 页面在下载前发生变化
- **WHEN** 采集后页面修改图片标题、导航或用户编辑下载标题
- **THEN** 已采集图片保留当时的来源、原标题和时间，不将下载时间或新的页面信息伪装成采集信息

#### Scenario: 多处出现同一图片地址
- **WHEN** 同一 URL 在多个文档或元素被合并为一个候选
- **THEN** 保留首次发现的完整溯源记录及既有可用读取入口，不将一个来源的标题与另一个来源的文档地址拼成虚假记录；重新扫描生成新扫描的采集记录

### Requirement: 已打开图库动态补充候选

系统 SHALL 在图库打开期间结合性能观察器（PerformanceObserver）、文档对象模型（Document Object Model, DOM）变化和图片加载状态，合并同一源文档的图片增量；覆盖可访问框架、换源及同地址复用。保留成功原图、有效选择、筛选与标题草稿，不自动滚动或创建网站尚未生成的图片。被动徽标仍仅使用页面元数据，不启动归档、图片请求或调试读取。

#### Scenario: 懒加载图片后来完成
- **WHEN** 用户在原网页展开内容，新增图片完成加载
- **THEN** 打开的图库补充候选并合并提取批次，不清空已有工作状态；页面导航后旧事件不更新新列表

### Requirement: 增强模式补充浏览器资源候选

系统 SHALL 仅在源网站已开启增强模式（Enhanced Mode）时，通过 Chrome 开发者工具协议（Chrome DevTools Protocol, CDP）的资源索引补充已加载但普通扫描未发现的图片，标明浏览器资源来源并保留所属文档溯源。新候选沿用范围、排除、去重、普通筛选及忽略规则。有范围约束而无法证明允许的资源不得加入。

#### Scenario: 资源没有对应页面元素
- **WHEN** 已授权网站的浏览器索引含普通扫描遗漏的已加载图片，且未限制采集范围
- **THEN** 将可验证所属文档的资源作为候选加入，不冒充有元素标题，不自动请求尚未加载的资源

#### Scenario: 浏览器资源落在排除范围
- **WHEN** 存在 XPath 或层叠样式表（Cascading Style Sheets, CSS）排除规则，资源不能对应到已允许元素
- **THEN** 不以增强模式绕过范围加入候选，已允许元素的同地址资源仅补充数据
