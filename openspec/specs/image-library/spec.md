# image-library Specification

## Purpose

规定侧边栏与独立图片库的共同交互，使图片选择、排序、加载反馈和网页上下文在不同宽度及语言下保持一致，同时避免界面装饰、状态变化或布局切换干扰用户已有的工作状态。

## Requirements

### Requirement: 紧凑网页上下文与响应式图库

系统 SHALL 同时提供侧边栏和固定源标签页的独立图片库，支持网格及列表。顶部品牌面包屑显示当前网页域名，保留面包屑字号；长域名省略并提供完整悬停说明，正文不再重复图片库大标题、总数与标题插画。

#### Scenario: 窄侧栏与长域名
- **WHEN** 用户在窄侧栏查看长域名页面
- **THEN** 域名不挤出操作按钮或造成横向溢出，网页标题仍可编辑

### Requirement: 卡片点击与框选

系统 SHALL 允许点击卡片空白区域或复选框切换选择，卡片中的操作按钮不触发额外选择。鼠标拖动框选默认追加，Ctrl / Command 框选反选，Esc 恢复本次手势前的选择，拖至窗口边缘时可自动滚动继续选择。

#### Scenario: 用户取消反选框选
- **WHEN** 用户按修饰键拖动后按 Esc
- **THEN** 恢复手势开始时的选择，不保留本次框选的临时改变

### Requirement: 全选与失败图片约束

系统 SHALL 让全选只选中当前可见且成功加载预览的图片，跳过失败、加载中及重试中的预览；取消全选清除当前列表的选择并保留筛选隐藏的选择。失败图片不能通过复选框、卡片或框选选中，已选项失败后自动取消选择。

#### Scenario: 全选后隐藏部分选择
- **WHEN** 用户改变筛选后取消当前列表全选
- **THEN** 仅清除当前列表内的选择，被筛选隐藏的选择保持不变

#### Scenario: 选中图片随后预览失败
- **WHEN** 已选图片的预览进入失败状态
- **THEN** 自动取消选择并禁用选择入口，重试成功后恢复可选择状态

### Requirement: 先按成功状态分组再排序

系统 SHALL 在成功图片优先设置开启时，把成功预览放在加载中和失败项之前，组内按当前排序；可选首次发现顺序、面积降序或宽度降序。首次发现顺序不承诺等同全局屏幕坐标，加载完成时间不作为组内排序依据。

#### Scenario: 后面的图片先加载完成
- **WHEN** 成功优先开启，若干图片以不同时间完成加载
- **THEN** 成功图片移动到前组，但该组仍按所选规则排列；关闭成功优先后恢复当前排序

### Requirement: 明确呈现选择与预览状态

系统 SHALL 只在有选择时，在全选开关右侧显示已选数量，不在底部单独占位。成功预览隐藏加载占位，失败预览使用中间破碎的图片图标并提供重试，空列表提供提示。

#### Scenario: 最后一个选择被取消
- **WHEN** 已选数量变为零
- **THEN** 隐藏已选数量文案，底部下载区不增加选择计数行

### Requirement: 网站规则摘要不遮挡下载区

系统 SHALL 在图片列表末尾显示当前域名已保存的 XPath 与 CSS 规则，未配置时明确标注；摘要随正文滚动，底部下载操作保持独立可见。

#### Scenario: 滚动到列表底部
- **WHEN** 用户滚动到当前页面最下方
- **THEN** 已保存的规则摘要完整位于下载按钮区域上方，未保存编辑不替换摘要
