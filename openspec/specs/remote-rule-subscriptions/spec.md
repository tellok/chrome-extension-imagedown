# remote-rule-subscriptions Specification

## Purpose

规定远程规则订阅（Remote Rule Subscription）的域名文件格式、页面地址匹配、配置继承及缓存更新行为，让用户能够独立维护采集规则，并在离线、订阅失败或规则错误时继续使用最后有效配置。

## Requirements

### Requirement: 管理多个远程规则订阅

系统 SHALL 在设置页独立分类提供添加、删除、逐项刷新与全部刷新，初始列表为空且不内置演示源。订阅在本机保存，按添加顺序排列，最多20项；重复地址不得重复添加。各项显示目标域名、源地址、最后成功时间和刷新状态，失败不报告成功。控件支持七种语言、明暗主题及320像素宽度。

#### Scenario: 添加多个订阅并重开
- **WHEN** 用户添加两个有效规则文件地址后重开设置页
- **THEN** 两项按添加顺序恢复，各自缓存和状态独立；刷新全部时单项失败不阻止其他项完成

#### Scenario: 删除尚在刷新的订阅
- **WHEN** 用户删除一个正在刷新的订阅
- **THEN** 其规则立即停止参与匹配，后续到达的旧响应不得重新创建订阅；不删除本地手动设置

#### Scenario: 无效或重复地址
- **WHEN** 输入重复地址、非 HTTP(S) 地址、含用户名密码的地址或不能识别域名的文件名
- **THEN** 阻止添加并显示具体原因，不创建伪成功记录；合法地址初次获取失败时保留可重试的错误项而不应用规则

### Requirement: 按文件名精确归属域名

系统 SHALL 从原订阅地址的最后路径段解析 `<hostname>.json`，忽略查询和片段，解码文件名并规范化主机名（Hostname）。规则仅归属精确匹配的顶层源页面主机名；图片服务器、内嵌框架域名和网络重定向不得改变归属。规则格式使用版本1的 JSON 数据，仅接收已定义字段，不执行远程代码。

#### Scenario: 同一文件的子域隔离
- **WHEN** 订阅文件名为 example.com.json，页面分别属于 example.com 和 sub.example.com
- **THEN** 文件仅参与前者的匹配，后者使用自己的配置；图片来自其他服务器也不改变归属

#### Scenario: 不支持的文件格式
- **WHEN** 文件不是有效 JSON、版本不是1、字段不受支持或字段类型非法
- **THEN** 拒绝整次更新并显示格式错误，不部分应用规则，不覆盖最后有效缓存

### Requirement: 顺序匹配页面地址

系统 SHALL 对完整源页面地址（Uniform Resource Locator, URL）执行正则表达式（Regular Expression）匹配，文件内最多100条规则，每条有非空且不超过256字符的 pattern、可选 id、可选 flags 与 options。flags 仅接受空值、i、u、iu；同文件取首条命中，同域多订阅取添加顺序中首个存在命中的文件。不得合并后续命中规则；没有命中时不贡献远程值。

#### Scenario: 路径命中与优先顺序
- **WHEN** 同域两文件均命中当前页面，首个文件内又有两条命中规则
- **THEN** 仅使用首个文件的首条命中规则；缺少的字段不由后续规则补齐

#### Scenario: 不同路径与无命中
- **WHEN** 相同主机名的两个页面路径分别匹配不同规则，另一页面未命中任何规则
- **THEN** 前两页分别采用各自命中项，未命中页面使用本地配置与既有默认

#### Scenario: 非法或超时正则
- **WHEN** 更新文件包含非法正则，或对当前页面的匹配超过1秒预算
- **THEN** 非法正则使更新失败；超时匹配停止本页远程解析并回退本地与全局默认，显示可诊断错误，不使设置、图库或徽标持续卡住

### Requirement: 远程只补充未配置的筛选项

系统 SHALL 仅允许远程 options 包含 width、height、minBytes、xpath、excludedSelectors、query、type、source、loaded、showIgnored。本地显式配置包括0、false和空字符串优先，未配置项使用命中远程值，否则使用既有默认；不能把远程有效值固化成本地覆盖。全局宽高是回退默认，不是网站手动覆盖。

#### Scenario: 显式取消远程限制
- **WHEN** 远程提供宽度400与搜索词，本地网站保存宽度0及显式空搜索
- **THEN** 宽度限制取消且搜索为空，其余未配置字段才继承远程；切换路径不改写本地配置

#### Scenario: 不支持的控制项
- **WHEN** 远程文件包含下载目录、界面语言、主题、清单开关、忽略摘要或可执行脚本等非允许字段
- **THEN** 拒绝该文件更新，不改变这些本机设置；完整原图数据与静态像素缩略图的获取及保存策略不变

#### Scenario: 字段边界与选择器校验
- **WHEN** 宽高不是0至100000整数、体积不是有限非负数、布尔值类型错误、枚举未知，或 XPath / CSS 语法无效
- **THEN** 拒绝更新并保留最后有效缓存；有效XPath只允许返回节点集合

### Requirement: 缓存与有界刷新

系统 SHALL 在本机缓存最后成功校验的文档，正常页面匹配直接使用缓存而不等待联网。订阅存在时每6小时安排刷新，启动时恢复缺失调度并刷新到期项，休眠可延迟执行。手动刷新立即尝试获取；网络、解析、存储或资源限制失败时保留有效缓存和最后成功时间，同时记录最近尝试及错误。

#### Scenario: 离线与后台重启
- **WHEN** 扩展后台重启或浏览器离线，已有有效缓存
- **THEN** 图库及未展开时的徽标继续使用缓存；到期刷新失败可见，不清空已生效规则

#### Scenario: 有界网络与缓存
- **WHEN** 单次获取超过10秒、文件超过256 KiB、总有效缓存超过4 MiB，或本机存储失败
- **THEN** 取消或拒绝更新并明确显示原因，保留最后有效配置；并发刷新同项不得互相覆盖新结果

#### Scenario: 空订阅列表
- **WHEN** 用户从未添加订阅或删除最后一项
- **THEN** 不继续定期请求远程规则，现有本地功能与默认值保持可用

### Requirement: 有效配置更新保持工作状态

系统 SHALL 在命中规则语义变化时更新受影响页面并展示远程来源；仅成功时间等状态变化不得重新采集图片。普通筛选变化复用已有候选和原图数据；仅XPath或CSS范围变化需要重新采集。保留未保存草稿及仍有效的选择，导航后旧页面结果不得覆盖新页面，下载批次开始后保持其配置快照。

#### Scenario: 远程阈值更新
- **WHEN** 已打开图库的远程宽度改变，而XPath和CSS不变
- **THEN** 基于既有列表重新筛选并同步徽标，不重新请求图片、不清空编辑草稿；不再可见的选择按既有筛选规则处理

#### Scenario: 下载过程中更新
- **WHEN** 下载批次进行中收到远程更新
- **THEN** 不改变本次下载文件、目录或清单；待批次结束才将新配置应用到图库

#### Scenario: 来源与长地址
- **WHEN** 图库采用远程默认值或显示远程XPath/CSS
- **THEN** 能辨认其订阅文件及规则来源；长地址可截断并有完整说明，不撑宽页面
