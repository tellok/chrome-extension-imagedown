# image-filtering Specification

## Purpose

规定网站采集范围、排除规则和普通图片筛选的组合行为，使用户保存的配置在同一网站重复使用，并让未知元数据、估算体积及图片忽略规则具有稳定且可解释的筛选结果。

## Requirements

### Requirement: 先应用网站采集范围

系统 SHALL 按 XPath 范围、CSS 排除、地址去重、普通筛选的顺序处理候选。XPath 匹配节点本身及其子树，非空 XPath 只作用于顶层文档；未配置 XPath 时允许采集可访问的 iframe。

#### Scenario: XPath 直接选择图片
- **WHEN** 用户保存的 XPath 匹配一个 img 元素
- **THEN** 该元素本身包含在范围内，不因没有子节点而漏掉

#### Scenario: 网站规则无匹配或语法错误
- **WHEN** XPath 有效但未匹配节点，或用户提交无效 XPath / CSS
- **THEN** 无匹配时显示空结果与提示而不退回全页；无效语法不保存

### Requirement: 排除匹配元素及其子树

系统 SHALL 支持每行一条或逗号分隔的 CSS 选择器，排除匹配元素及其后代中的各类图片。启用 XPath 或 CSS 排除时，资源记录只能补充已允许 DOM 图片的元数据，不能绕过排除新增地址。

#### Scenario: 广告图片已被资源时间线记录
- **WHEN** 广告容器被 CSS 排除，图片同时存在于资源记录中
- **THEN** 资源记录不将该图片重新加入列表；同地址若另有未排除的允许元素引用则仍可保留

### Requirement: 网站规则与搜索按 hostname 隔离

系统 SHALL 以顶层网页 hostname 保存 XPath、CSS、搜索及忽略规则，不区分协议、端口或路径，并区分不同子域名。iframe 与 CDN 图片的规则归属顶层网页域名。

#### Scenario: 重开同网站页面
- **WHEN** 用户打开同 hostname 的另一条路径或重新扫描
- **THEN** 恢复该网站的 XPath、CSS 和搜索；不同 hostname 不复用这些内容

### Requirement: 默认阈值与普通筛选

系统 SHALL 默认使用最小宽度 50 px、最小高度 50 px、最小体积 2048 字节；低于任一阈值时隐藏，等于阈值时保留，未知尺寸或体积不因未知本身被隐藏。普通筛选支持 URL / 描述搜索、格式、发现来源及页面加载状态。

#### Scenario: 阈值边界与未知数据
- **WHEN** 候选恰好达到阈值，或尚无可用尺寸 / 体积
- **THEN** 不因低于阈值而隐藏；后来获得元数据时重新应用筛选

#### Scenario: 保存与重置筛选
- **WHEN** 用户修改阈值、格式、来源、加载状态或显示忽略项
- **THEN** 保存并同步已打开的面板；阈值为 0 时取消对应限制

### Requirement: 区分精确体积与估算体积

系统 SHALL 优先显示已知的图片数据字节数，未知时按像素尺寸和格式估算并标记约数。估算参与体积筛选，错误 HTTP 响应体、响应头字节数和解码像素内存不得当作原文件大小，也不得仅为体积计算批量额外请求图片。

#### Scenario: 403 响应包含 HTML 错误页面
- **WHEN** 图片地址返回错误响应及非图片内容
- **THEN** 不将错误页面字节数显示成图片原文件体积

### Requirement: 稳定忽略与恢复

系统 SHALL 默认隐藏已忽略图片并取消其选择，允许显示忽略项和逐项恢复。规则只保存版本化 SHA-256 标识：URL 包含完整地址但不受可变尺寸影响，Data URL 按解码内容识别，Blob / Canvas 使用可用像素与尺寸识别；没有稳定标识时禁用忽略入口。

#### Scenario: 同一图片地址的元数据变得完整
- **WHEN** 忽略后重新扫描获得新的尺寸、MIME 或体积
- **THEN** URL 图片的忽略规则仍有效；等价 Base64 编码也不能绕过相同内容的忽略规则

#### Scenario: 多面板同时忽略图片
- **WHEN** 两个面板同时为同一网站新增忽略项
- **THEN** 两项修改都保留，不因并发覆盖而丢失

### Requirement: 区分网站规则和普通筛选清除

系统 SHALL 在清除网站规则时只清除该域名的 XPath 与 CSS；清除普通筛选不更改网站规则或忽略记录，恢复默认阈值也不清除搜索记忆。

#### Scenario: 用户只恢复尺寸阈值
- **WHEN** 用户点击恢复默认阈值
- **THEN** 宽高体积恢复 50 / 50 / 2048，已保存的搜索、网站规则与忽略记录保持有效
