# image-data Specification

## Purpose

规定候选图片如何成为可预览或保存的数据，优先复用扩展已有的完整原文件和浏览器保留资源，同时将静态像素缩略图与原始压缩字节明确区分，避免重复请求及动画或文件内容被误替换。

## Requirements

### Requirement: 复用已取得的完整原图

系统 SHALL 直接复用已持有的完整原图 Data URL 或 Blob 保存文件，不重新请求源地址，也不以原网页已导航或不可访问为由丢弃这份数据。当前列表内的后续完整读取与下载复用同一原图数据。

#### Scenario: 原数据已经取得而原网页失效
- **WHEN** 扩展已持有完整图片数据，原文档随后不可访问
- **THEN** 保存该份本地数据无需再次访问原文档或服务器，保存字节与原数据一致

### Requirement: 静态缩略图不冒充原文件

系统 SHALL 区分完整原文件与像素缩略图，不将静态 PNG 缩略图放入原图复用缓存，也不得让并发缩略图读取替代原文件下载的读取。成功读取原始 GIF / WebP 数据时保留其原始动画字节。

#### Scenario: 预览和原图下载同时读取动图
- **WHEN** 预览使用静态像素，而下载同时读取原 GIF 文件
- **THEN** 下载得到完整原文件，不共享预览的静态缩略图结果

### Requirement: 优先尝试浏览器保留的原始资源

系统 SHALL 在无本地原图时尝试通过短暂调试连接读取当前源文档保留的原始图片资源，不为此刷新网页、禁用缓存或请求图片 URL。读取资源前后校验源文档身份，结束后释放本次拥有的连接。

#### Scenario: 网页显示无 CORS 授权的跨域动图
- **WHEN** 浏览器仍保留该动图资源
- **THEN** 扩展可取得原始字节用于预览与下载，图片服务器请求数不因这次资源读取增加

#### Scenario: 调试连接不可用
- **WHEN** 其他调试器占用连接、资源已释放，或用户取消本次调试
- **THEN** 允许使用其他读取路径，不断开他人拥有的连接；用户取消后不在当前文档反复重新连接，导航后才可再尝试

### Requirement: 提供原图读取回退并呈现来源

系统 SHALL 在浏览器原始资源不可用时依次利用页面内嵌数据、所属页面的 Blob / Canvas 快照、可用页面缓存与页面请求、允许导出的页面像素以及扩展请求；失败需保留原因。预览标记区分浏览器原始资源、页面提取和 URL 加载，不能把 URL 加载直接等同于发生新的网络请求。

#### Scenario: 当前只有可读页面缩略像素
- **WHEN** 预览重试可直接取得已显示像素，但还没有完整原文件
- **THEN** 可使用静态缩略图展示，原文件下载仍需继续尝试完整数据来源

### Requirement: 单张与批量预览重试

系统 SHALL 提供单张和全局失败预览重试。全局重试包含被普通筛选隐藏的失败项，默认跳过忽略项；显示忽略项时可重试它们，尚未触发加载的离屏预览不当作失败。

#### Scenario: 当前搜索隐藏了部分失败图片
- **WHEN** 用户执行重试所有失败图片
- **THEN** 仍重试这些已发现的失败项，汇总成功与失败数量，持续失败的项目保留入口

### Requirement: 重试不破坏现有任务状态

系统 SHALL 让预览重试保持筛选、忽略记录、其他已选项及下载结果，不自动下载；读取重试需要更新 HTTP 缓存时不改写 URL 的查询参数。成功后更新元数据并重新应用筛选，旧文档任务不得覆盖新页面列表。

#### Scenario: 带签名地址的预览重试
- **WHEN** 用户重试带查询签名的失败图片
- **THEN** 不添加随机查询参数，成功后保留本次预览用于布局切换，失败可再次重试

#### Scenario: 重试期间切换源网页
- **WHEN** 旧网页的重试在新网页扫描后完成
- **THEN** 旧结果不写入新列表；重试进行时下载操作保持禁用，避免冲突
