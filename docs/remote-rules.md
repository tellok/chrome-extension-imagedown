# 远程规则订阅

在设置页“远程规则订阅”添加返回原始JSON的HTTP(S)地址，可添加多个、逐项刷新、全部刷新或删除。出厂列表为空。文件名决定精确的源页面域名，例如 `example.com.json` 只适用于 `example.com`，不包括子域；重定向及图片服务器不改变归属。

## 文件格式

```json
{
  "version": 1,
  "rules": [
    {
      "id": "gallery",
      "pattern": "^https?://example\\.com/gallery(?:[/?#]|$)",
      "options": {
        "width": 200,
        "height": 120,
        "minBytes": 4096,
        "xpath": "//main",
        "excludedSelectors": ".advertisement, [data-ad]"
      }
    }
  ]
}
```

`pattern` 对完整源页面地址做JavaScript正则表达式（Regular Expression）匹配，最多256字符；可选 `flags` 仅接受空字符串、`i`、`u`、`iu`。`id` 可选，非空且最多80字符，同文件不能重复；省略时显示序号。文件最多100条规则，空列表可撤销其远程配置。顶层只接受 `version: 1` 与 `rules`；每条只接受 `id`、`pattern`、`flags`、`options`，未知字段拒绝整份更新。

| options字段 | 类型与含义 |
| --- | --- |
| width、height | 0至100000整数，像素；0取消限制 |
| minBytes | 有限非负数，字节；0取消限制 |
| xpath | 最多4096字符，必须返回节点集合；空字符串表示全页 |
| excludedSelectors | 最多4096字符，CSS选择器；每行一条或逗号分隔 |
| query | 最多512字符，图片地址/描述搜索 |
| type | 空字符串或jpg、png、webp、gif、svg、avif、bmp、ico、unknown |
| source | 空字符串或img、css、pseudo、canvas、svg、lazy、srcset、resource、poster、link |
| loaded、showIgnored | 布尔值，对应页面加载状态筛选与显示忽略项 |

下载位置、清单、忽略摘要、语言、主题等不接受远程配置。远程文件是数据，不支持脚本和模块。

## 优先级与继承

同域多订阅按添加顺序，文件内按规则顺序，只采用首个命中的文件的首条命中规则，不与后续规则合并。本地显式字段优先，其次是该远程规则对应字段，最后是既有默认。网站宽高没有两者时使用全局默认，体积回退2048字节。全局宽高是默认值，不是硬性下限。

本地 `0`、`false` 和空字符串也是显式选择，不被远程覆盖。格式/来源/加载状态等沿用原来的全局视图对象保存方式，手动修改会保存这一组本地选项。宽高还原按钮删除网站覆盖，重新继承远程默认或全局默认；占位和按钮说明会显示来源。清除网站规则会保存本地空XPath/CSS，禁用对应远程限制；存在远程搜索词时，清空搜索会保存本地空值。

## 缓存与错误

每6小时安排刷新，启动恢复到期更新；浏览器休眠可能延后。打开网页直接使用缓存，不为每次匹配重新获取订阅。网络或校验失败保留最后有效规则与成功时间，设置页展示最近错误。删除订阅立即停止应用它的缓存，不删除本地设置。

最多20项、单文件256 KiB、有效缓存总计4 MiB；获取10秒超时，正则匹配1秒超时。匹配超时终止工作线程并回退本地/全局，图库提示原因。规则更新不会改变已经开始的下载批次。

新增 `alarms` 权限用于调度，`offscreen` 用于本地工作线程及选择器校验；均不需要启动图片调试读取。获取订阅不携带Cookie或当前页面Referrer，也不上传页面地址或图片。使用Gist时应添加raw文件地址；不公开列出的Gist仍可被知道地址的人访问，不要存放秘密。
