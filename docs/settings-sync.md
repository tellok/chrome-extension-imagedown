# 配置同步

设置页的「配置同步」平时只显示「在此机器同步配置」开关，默认开启。只有出现配置冲突时，才展示版本选择和按需展开的差异。开关只保存在当前 Chrome 配置中；每台机器可以独立关闭。关闭后仍可正常使用和保存本机设置，不删除 Chrome 同步存储里的内容，也不改变其他机器的开关。

跨设备需要相同扩展标识、同一 Chrome 账户及浏览器同步。开发者模式加载时也须保证扩展 ID 相同。本功能不申请账户检测权限，不弹出登录，也不提供自有后端。开关表示本机是否参与同步，不能证明 Google 已送达其他机器；界面不展示存储写入状态。未开启浏览器同步时 `storage.sync` 仍可在本机保存；离线时由 Chrome 在可用后处理传输。

## 同步范围

| 会同步 | 只留本机 |
| --- | --- |
| 语言、主题、标题清洗、成功图片优先、下载清单开关 | 当前机器的同步开关、设备随机标识、同步状态及备份 |
| 全局默认最低宽高、全局格式/来源/加载/显示忽略项筛选 | 旧版全局最低体积、标签页和下载历史、标题及未保存的规则草稿 |
| 每个网站的最低宽高和体积、XPath、CSS、搜索词、忽略图片的 SHA-256 摘要 | 目录授权和句柄、图片数据、预览与规则缓存 |
| 按优先顺序排列的订阅地址 | 订阅本机 ID、规则文档、刷新时间和错误 |

网站以顶层页面 hostname 隔离，不区分协议、端口或路径，子域独立。搜索词、网站域名及订阅地址会随配置复制给 Chrome。忽略记录仅复制摘要；不会上传图片。订阅产生的有效默认值不转存为网站手动覆盖。

未设置与显式 `0`、`false`、空字符串含义不同。采用完整版本时，缺失字段恢复继承，显式空值仍覆盖对应远程默认。未单独配置的网站继续采用现有继承规则。

## 冲突与重试

启动、恢复、同步数据变化时自动比较。本机修改先立即保存，约2秒后聚合，自动发布间隔至少10秒；每5分钟重新检查或重试。真正空的同步命名空间可首次发布本机，相同内容确认一致。已知共同版本后仅本机改变时自动发布。

收到与本机不同的版本会提示选择，继续保留本机使用，不自动导入或按修改时间覆盖。设置页提示选择「使用本机设置」或「使用同步设置」，「查看差异」默认收起。单个同步候选无需辨认设备标识；多个候选以版本编号和时间区分，可逐项比较。离开页面不会做选择；本机或候选变化后原选择会失效，需要重新比较。没有自动字段合并。

确认选择后本机保留最近三份选择前备份，仅用于安全留存，不提供备份管理界面。采用另一机器的订阅地址时，同址保留本机缓存，新地址由本机获取，删除项的旧请求不能复活它。图库保留成功预览、草稿及仍有效的选择；下载中的文件、格式、目录、标题和清单沿用批次开始时值，范围变化延后。

关闭会停止新的同步读写、定时检查与应用。已经提交给 Chrome 的请求无法撤回，但其失效结果不会继续触发下一阶段。重新开启先比较；关闭期间两边不同会再次提示。

用户主动操作或初始化读取失败时，界面仅显示简短提示及此时才出现的「重试」。重试重新读取和比较，不会自动重放过期版本选择；需要时重新选择，恢复后反馈收起。

## 容量与错误

Chrome 同步存储总量约100KiB（102400字节），单项8KiB，最多512项，每分钟120次、每小时1800次写入。配置编码、多个设备版本、旧新版本安全更新都占空间，实际可用配置容量小于100KiB，不能容纳无限搜索或忽略记录。扩展每个新增项保留7KiB预算，并预检总量与临时空间。

超限不截断或删除配置，也不删除其他设备版本来腾空间。后台保留诊断并自动重试，本机仍可用；减少配置后会重新比较，也可关闭此机器同步。设置页不常驻展示配额或其他技术诊断。读取、写入、未知格式、损坏、分片未到齐时保持本机和最后有效数据；缺片不当作用户删除设置。

## 开发格式与验证边界

`settings-sync-codec.js` 使用版本1完整载荷：`{version:1, settings:{}, sites:{}, subscriptions:[]}`。三段均必须存在，未知字段拒绝整份。确定性 JSON → UTF-8 → SHA-256 摘要 → Base64 分片。每设备每修订使用不可变 `config-sync:v1:<device UUID>:<revision UUID>:head` 及编号分片；先分片后头，完整读回后清理本设备被支配旧版本。

头中的版本向量记录各设备因果计数，时间仅用于显示。互不支配且内容不同的分支保留为候选；确认选择只解决已观察的版本，后来的未见分支仍须比较。头缺少其引用数据时不应用半份。中断写入的自有分片依本机操作记录回收，不清理其他设备未知数据。

本机完整导入用一次 `storage.local.set` 写入配置、订阅对账、备份和事件标识。内部 `null` 墓碑表示恢复未设置，读取器沿用缺省语义，导出时省略；常规手动还原仍删除键。共享配置锁为 `imagetaken-config-write`，订阅串行队列先于配置锁，锁内不等待网络获取。

运行 `npm test` 验证18项同步单元用例，`python tests/settings_sync_browser_test.py` 验证13项真实 Chrome 浏览器场景。浏览器测试仅使用临时配置和测试桥接复制原生 `storage.sync` 记录，覆盖乱序、并发和配额；**不等于 Google 同步服务的真实跨账户端到端验证**，不触碰个人浏览器资料。

依据：[Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage)、[Web Locks](https://w3c.github.io/web-locks/)。

网站“增强模式”授权仅在本机保存，不参与配置同步；选择同步版本不会授予、修改或清除本机网站授权，远程规则同样不能开启此功能。
